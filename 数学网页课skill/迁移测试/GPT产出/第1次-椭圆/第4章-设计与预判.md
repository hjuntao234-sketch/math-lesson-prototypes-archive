# 主线第 4 章 · 先数清，再下笔

题源为学科罗盘「圆与椭圆」课程包攻坚 h1，核对原记录的题面。面向基础弱的高一、高二学生。建议两次放学后分开走，每节约 20 分钟为设计估计。

## 顺序和要学会的事

- 第 1 节「另一个顶点去哪儿」先对固定的 $a=2$ 按习惯报数并选想法、来源。夏海从左右对称找到一组，静在方格上验出镜像有时凑不成直角，也验出直角可以由下移量不同的两点组成。由此引入逻辑观念「等价转写」：旧问题的每个对象都要找到，新写法里的对象也要验回去。数格阶梯 $(1,1)\to(2,1)\to(3,2)$ 后，先问落点在哪、为什么只取向下的一次旋转。拖着找具体落点，换数，最后用 $u,v$ 写；把两点在椭圆上分别写成等式。练习先撤掉提示，换位移和换条件。
- 第 2 节「什么时候多出两个」回忆两问后，先猜个数是否会变，再选猜法和来源，回看试图只用对称性、只看一幅图等习惯。拖 $a^2$ 记录临界值两边和临界值的图，再证明。相减得 $(u-v)[(1-1/a^2)(u+v)-2]=0$。$u=v$ 时直接找到唯一正数解；$u\ne v$ 时先做「同一个差的两个平方」「知道和、差能否找回两数」的阶梯，再用相加式求差平方。逐个验负、零、正，换回 $a$。练习换参数，换条件，回看原写法和方法。
- 四问板落在「找旋转后的落点」「两顶点都上椭圆」「为何分两支」「已知和、差平方如何找回」「按 $a$ 数解」。绕远后拉回落在方格第一轮、写坐标前、滑尺后、差平方阶梯后。
- 方法卡四张，按首次用完的顺序发：从落点倒推、两个点分别代入、乘积为零逐个查、由和与差找回两数。逻辑观念不借历史人物或引语。

## 预判表

| 错成什么 | 为什么会这么想 | 页面怎么接 |
|---|---|---|
| $a=2$ 写 1，并断言两点一定等高 | 先画出最显眼的对称图，习惯把一个例子当全部 | 原答照录；$(2,-1)$ 与 $(-1,-2)$ 等长且垂直，下移量却不同；最后用精确计数对照 |
| 把另一个点写成镜像位移 $(-2,-1)$ | 见到椭圆就用左右对称 | 方格试答判镜像；对应回应点明一横一下互换，镜像会保留原下移量 |
| 取朝右上方的旋转 | 记得旋转两种方向，漏掉椭圆顶点位置 | 旋转卡先算具体坐标，拖动时当场报落点高过 $A$ |
| 允许两点同侧 | 图上只看折角，没把两条边都向下纳入 | 两边在同一开象限时夹角小于直角；画轴上例外，回到一左一右 |
| 把轴上的下顶点也当可用的 $B$ | 觉得在椭圆上即可 | 针对性判断；它的垂线过 $A$ 且水平，只有 $A$ 本身在椭圆上 |
| 把下移 $2$ 后的纵坐标写成 $3$ 或 $-2$ | 把向下当加，或把位移当坐标 | 数字错答分别提示方向和起点；卡中先在 $0$ 向下，再从 $1$ 向下 |
| 只代右边的点 | 误以为有直角且等长就自动同时上椭圆 | 分别代入；指出旋转保证边的性质，椭圆一般不保持绕 $A$ 的旋转 |
| 两边同除 $u-v$ | 习惯先约掉同一因子 | 拆成具体乘积，专门保留 $u=v$ 的一支 |
| 对称支把 $u=0$ 也数进去 | 解到方程根便照抄 | 代回顶点重合；拆成「根是什么」「它能当顶点吗」 |
| 把 $(5-1)^2$ 写成 $24$ 或 $4$ | 平方错误地分到两项，或漏掉最后的平方 | 错答分支；先算括号再平方；乘法小步可再拆一层 |
| 差平方只取正差 | 开平方只写算术平方根 | 和为 6、差平方 16 时找两对；再拆细看 $4,-4$ 的平方 |
| 差平方为零时再加一个 | 将两个分支当作天然互不重合的清单 | 拆细：差为零推出 $u=v$，非对称支要求 $u\ne v$；滑尺停在精确临界值对照 |
| 把 3 当成 $a$ 的分界 | 滑尺标的是 $a^2$，漏掉回到原题 | 定位条切回原题参数；专门比较 $a^2=3$ 与 $a=\sqrt3$ |
| 把交换 $u,v$ 当成给同一三角形重命名 | 没固定哪个点记作 $B$ | 固定 $B$ 为右边点，互换后其横坐标改变；在图上区别于同一三角形的顶点换名 |

## 拆细和验证范围

剧本采用范例的问答、拆细和方法卡外观。拆细覆盖方向、轴上特例、落点、坐标、分别代入、保留零因子、去掉退化解、差平方、正负两差、边界去重、换回参数以及重新对焦和变式。坐标卡的起点与差平方卡的乘法各有第二层。拆完回到原问。数题只把可读的错误数值计入拆细次数，沿用范例的解析行为。

数学验算另用过 $A$ 的斜率，另外逐项验位移、坐标、差平方、分界与变式。脚本走查只能验证模拟作答及浏览器行为。学生的实际用时、提示能否自行撤掉、过几天是否还会做，以及真实手机触屏体验，待审读或试课。
