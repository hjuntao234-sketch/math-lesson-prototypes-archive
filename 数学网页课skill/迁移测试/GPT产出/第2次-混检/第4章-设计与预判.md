# 主线第 4 章 · 大组就更省吗？

题源为罗盘「随机变量与成对数据」课程包攻坚 h1，只核对题面。对象是基础弱的高二学生，沿用题设的理想检测规则。

## 两节

1. **一组到底要测几次。** 夏海念题。确认要求，先报 $k$，再选四种想法和四种来源。夏海只数首次混检，有村静先承认只算固定部分的习惯，再拿一组触发复检的情形对照。黑羽灯带来拉普拉斯《概率的哲学试论》（1814 年），四轮问答把「次数按概率加权」接到题上。第一处阶梯用两人的四种结果（各以 $1/2$ 的概率感染）走到原题两人组，再逐行写任意 $k$ 的平均每人次数。第二节开头会用到这一式。两道练习分别换组大小、换感染率。
2. **再加一人，省还是费。** 两道回忆后先猜何时该停，并记录来源。自己拖动 29 档滑尺，先写猜值，再用精确的相邻差解释。第二处阶梯先确定「后一项减前一项」的符号，再完整算 $k=2\to3$。用字母重走，找出决定差值正负的量 $R_k$。证明 $R_k$ 递增，再逐行验 $R_{10}<1<R_{11}$，得到唯一最优。两道练习撤去原数据，分别换相邻两项与临界条件。

四问板用于找平均次数、滑尺上找最低点、从相邻差到全范围。方法卡依次为「反过来算一次」「按概率加权再平均到人」「看相邻两项的差」。此题的构造落点是选择整数 $k$ 使平均每人次数最小，先指定落点标准再试、换数、写成字母；没有另造一个辅助数。

## 预判

| 错成什么 | 为什么 | 页面怎样接 |
|---|---|---|
| 选 30，只算首次混检 | 固定的一次摊给越多人越少 | 对照 2 人阳性组实际测 3 次，再分清总次数与首次的摊派 |
| 一组阳性时填 2 次 | 把逐一检测当成只再测一次，或漏首次 | 从 2 人逐个数，再加首次，拆细追问首次和追加 |
| 把感染人数多当成目标 | 见到阳性就想到找人 | 念题确认目标；定位条始终区分 $k$、阳性概率、平均次数 |
| 算「全感染」来当阳性概率 | 把「至少一人」看成「人人」 | 四格逐个判，再用「全未感染」取补；两人具体数拆细 |
| 四格都列了，却觉得正好一半阳性 | 把两类当成等可能 | 第一阶列四个等可能结果，三个阳性；加权按概率分配 |
| 把 $2\%$ 当两人组阳性概率 | 把两人的感染概率直接相加 | 同时感染算了两遍，精确结果 $0.0199$；乘法可进第二层 |
| 用 $(1+3)/2$ 算平均 | 熟悉两个数各占一半的平均 | 用四格计数得到组均值 $2.5$，回原题重新分权重 |
| 写 $1.0398$ 就停 | 没区分每组和每人 | 黑板分行写单位，按 2 人摊；拆细先用整次数 |
| 任意 $k$ 忘记独立就乘概率 | 只记得连乘公式 | 特设「若状态不独立」迁移判断，指出题设为何关键 |
| 用 $0.99^k$ 乘复检次数 | 记住幂但套错分支 | 黑板并排标阴性、阳性；指出 $k$ 是哪条分支的追加次数 |
| 看到差为负还以为后一项较大 | 把相减方向记反 | 先用 $0.2,0.3$ 再用 $2\to3$；负分数可进第二层 |
| 把 $1/3-1/2$ 写成 $1/6$ | 只记差的大小 | 通分写 $2/6-3/6$，再回原问 |
| 一对相邻值变大就宣布全程增 | 把局部当全局 | 用 $R_{k+1}/R_k>1$ 保证之后持续为正 |
| 四舍五入以为 $10,11$ 并列 | 前几位太接近 | 滑尺显示 7 位小数，最终用精确分数不等式分辨 |
| 把 $R_{10}<1$ 当作最优 $k=10$ | 忘记下标指从 10 到 11 | 数轴式顺序板写「10 → 11 仍变小」，再判断 11 → 12 |

## 拆细、史料和验证范围

首层覆盖目标、次数、取补、独立相乘、按概率加权、摊到人、相减方向、通分、单调、临界下标、拉回和变式。两人阴性概率的乘法、相邻差的负分数各有第二层。量化用时为设计参考，真实学生、延迟记忆和触屏待检。

拉普拉斯的法文初版 *Essai philosophique sur les probabilités*（巴黎，1814）核自[法国国家图书馆书目](https://catalogue.bnf.fr/ark%3A/12148/cb30739024c)及 [ETH 初版扫描](https://www.e-rara.ch/download/pdf/1340542.pdf)。[初版第 146 页](https://www.e-rara.ch/zut/content/pagetext/1090900)回述把各结果与其概率的乘积计入期望。中文书名采用意译。页面是读书后的校园对话，台词转述原则，混检是本章的应用。
