## 出图与后期

使用 Codex 内置 OpenAI ImageGen。工具回执未披露底层模型版本。夏海、静、栞保留透明底方式生成。美羽第一轮附 `image3.jpeg`，触发出图工具的输出审核，第二轮以本批静的及膝校服立绘作风格和校服参照，得到透明底成品。其余角色首次附图依次为夏海 `image4.jpeg`、静 `image.jpeg`、灯 `image1.jpeg`、栞 `image2.jpeg`。各轮实际提示词、附图与次数见 `出图记录.md`。

灯的平静表情使用第一稿的立绘轮廓与透明度，并局部取第二稿生成的嘴部。栞重出时移除了开衫内误生成的针织背心，并把头发压到灰棕。夏海的第一轮表情编辑出现底色残留与全身细微重绘。改成由同一选中底图加技术绿底再编辑，抠除绿底后，仅在对应区域使用生成像素。局部处理用于固定构图与原始画面的衣服、道具、身体，其它区域沿用同一平静底图。

`tools/prepare_sprites.py` 可复现后期，依赖 Pillow 与 NumPy。命令为 `python3 tools/prepare_sprites.py --references ~/Desktop`。直接输出透明 PNG 与检查图，测量和哈希以 JSON 输出，留档见 `tools/测量.json`。

- **画风。** 发丝高光、干净细线、服装格纹和浅暖光与参考图有明显关联。平铺对比时，本批为了立绘用途采用全身平视且透明，阴影比带场景的参考图略均匀。冷暖光是否已够接近，留给 Claude 看对照图判断。
- **脸部。** 五人平静图双眼和主要脸部轮廓可见。单看眼型和下颌，夏海更圆、静更窄平、美羽眼尾上挑、灯下巴最尖、栞脸颊柔圆。美羽和灯最容易在去掉发饰、发色和虹膜色后显得接近，适合重点复核。
- **剪影及灰度。** 差异见盲测答案中的五条轮廓依据。五人的头发中段选区做 0–255 灰度中位数抽样，见比例表，顺序为静 < 栞 < 夏海 < 美羽 < 灯。发丝高光的局部亮度会交叉。
- **圆形头像。** 9 张各为 512×512 透明 PNG，五位平静图使用同一眼线高度，约 y=215（42%）。用 96 px 圆形实际预览检查了平静图，眼睛、脸廓和标志性发型上端在圆内。长直发和辫子在肩线附近自然出框，圆头像保留脸与头肩区域。夏海所有表情复用同一裁切矩形；困惑与着急的拳臂在圆形框下侧会被截到。
- **表情切换。** 平静闭嘴微笑，笑为闭眼张嘴，困惑为嘴歪、抬眉并以一指触颊，惊讶为睁眼 O 形口加马尾末端上翘，着急为汗滴、咬牙与双拳抬起。比较成品的缩放和定位一致。原尺寸编辑区域外 RGBA 逐像素一致，缩放后在编辑区域外加 4 px Lanczos 边界也无差异。手臂动作连带局部卷袖褶皱，惊讶含交接指定的马尾末端变化。
- **透明边缘与文件。** 全身图 1024×1536，头像 512×512，均为 RGBA，有实际透明像素。重出表情的绿键经去溢色，另清理缩放在弱透明边缘产生的高饱和伪色。按脚本的绿与品红阈值扫描，18 张图半透明区域均无命中，灰底也做过目视核对。
- **课堂画面。** 以高中生造型、平视、人站立和自然动作为目标。裙长视觉上到膝附近，个别随站姿露出部分膝盖。没有超过膝盖的袜子、低角度和暴露或暗示性姿势。灯的绷带是整洁的白色装饰，未见伤口或血迹。逐张看过秒表、屏面道具、臂章、盾牌、夹板、书面、标签、素描本及衣鞋，未见字、数、内容标识或水印。设计是原创角色，目视未看到刻意复刻的现成角色特征。

## 请 Claude 拍板

- 最满意 **黑羽灯** 与 **有村静**。灯的异色瞳、羽饰、双马尾、披肩与施法手势同时成立，正脸仍清楚。静的狭窄眼型、站姿和长直发在五人阵容内清晰，服装和道具也符合设计。

- 先做两张盲测，再决定 96 px 实际显示时脸部大小、静与美羽及灯的眼型区分、五人的整体光感是否达标。夏海只需复核表情是否够好认，以及「困惑」「着急」的手势在圆头像下半部露出的程度。
