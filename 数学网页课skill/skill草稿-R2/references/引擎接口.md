# 引擎接口

引擎就是小样里的 `app.js`、`chapter.js` 前半部分、`style.css`。新章节只调用下面这些，不改它们。范例：`chapter.js` 的 `chapter1`、`chapter2`，`stress.js` 的 `ch3s1`、`ch3s2`、`ch3s3`。

## 剧情和问答（都返回 Promise，用 `await`）

| 函数 | 作用 |
|---|---|
| `talkP([[人, 台词], …])` | 一段对话，点一下往下。人：`natsumi`、`akari`、`shiori`、`shizuka`、`miu`、`班主任`、`旁白` |
| `chooseP(人, 问题, [选项…])` | 选择，返回下标。不打乱，用于自报想法、选节这类没有对错的 |
| `inputP(人, 问题, 占位提示)` | 填空，返回原文 |
| `quizP(人, 问题, 选项, 对的下标, 错时回应, 拆细?)` | 一直问到选对。显示顺序自动打乱（同一问重答时顺序不变），下标仍按你写的顺序。错时回应是数组，每个选项一项，形如 `[[人, 台词], …]`；对的那项写 `null`。自己包一层函数时也要调 `quizP`，别直接用 `chooseP` |
| `numP(人, 问题, 答案, 回应, 拆细?)` | 填数，一直问到对。回应写成 `Object.assign([[错的值, [[人,台词]]], …], { other: [[人,台词]] })`。写成 $-f(1)$ 这类“对但没算完”的，会自动提示 |
| `exprP(人, 问题, 答案函数, 回应, 拆细?)` | 填含 $x$ 的式子，在负数点上比对。正数点版本见 `stress.js` 的 `exprPos` |
| `scene(lines, done)` | `talkP` 的回调版 |

台词和问题里可以写 `$…$` 公式和 `<b>…</b>`。

## 拆细数据

```js
const DD_X = { 标题: '$-1$ 和 $0$ 谁大', 为什么: '你在“$-1>0$ 吗”这里两次没过。先把比大小拆开。', 步: [
  { 说: '可选的说明', 型: 'pick', 问: '…', 选: ['…', '…'], 对: 0, 提示: '…' },
  { 型: 'num', 问: '…', 答: -3, 提示: '…', 拆: DD_更细 },          // 这一小步两次没过，再插一层
  { 型: 'expr', 问: '…', 答: x => x * x, 示: 'x^2', 提示: '…' },  // 示：第三次没过时给出的答案
] };
```

## 舞台

- `view(html)`：换整页内容。
- 主线章节的舞台写法参照 `chStage`、`chStage3`：题目条 `.qline`、拆细容器 `<div id="ddhost"></div>`、黑板 `<div class="chalk" id="chalk">`。
- `chalk([[标签, 内容, 'ok'|'bad'|'mine'?], …])`：重写黑板。
- `hl(id)`：高亮题目里带 id 的那几个字。
- `plotD(f, x0, opts)`（在 `stress.js`）：函数图像加水平线的模板。画别的图时，参照它的写法自己写 SVG。

## 定位

- `whereSet({ 题, 要, steps: [...], doing })`：开一节时调用。
- `whereStep(i, doing)`：走到第 i 步（从 0 起）；`i` 传 `null` 表示只改“现在”那一行。
- `yao(新的要什么)`：换问时改“要”（在 `stress.js`，可抄过去）。
- `whereOff()`：回教室时调用。

## 记录

- `SV`：存档，`save()` 写盘。每章用自己的键，比如 `SV.ch4`。
- `CUR_CH = 'ch4'`：开章时设，拆细记录会按章分开。
- `ddList('ch4')`：回头看里列出这一章拆过的地方。
- 方法卡：照 `stress.js` 的 `M3` 和 `method(k)` 写一份自己的。

## 判对错的工具

`numStep(原文, 答案)`、`exprTest(原文, 'x', 点列, 函数)`、`sameAs(fn, 'x', 点列, 函数)`、`near(a, b)`、`cx(原文)`（把原文读成函数）。

注意：
- 读式子只认 `x`、`a`、数字、`+ - * / ^ √ ( )`。题目要用别的字母时，问题里写明“把 $k$ 写成 $x$”，或者改成选择、填数。
- `numStep` 里写 `f(…)` 时，用的是第 1、2 章那个函数（$x>0$ 时 $x^2+2x$ 的奇函数）。新章节别让学生写 `f(…)`。
- `exprP` 只在负数点上比对；要在正数点上比对，照 `stress.js` 的 `exprPos` 写一个。

## 入口

一共三处，别的地方不准改：

1. `app.js` 的 `hub()` 里，照 `tCh3` 那张卡加一张；
2. `app.js` 里加一行 `$('#tCh4').onclick = () => chapter4();`；
3. `index.html` 在 `stress.js` 那行后面加一行 `<script src="ch4.js"></script>`。
