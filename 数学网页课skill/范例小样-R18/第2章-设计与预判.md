# 主线第 2 章 · 空着的位置（弗雷格）· 设计与预判

还是那道题，换成问“$x<0$ 时 $f(x)$ 的解析式”。用户 11-13 指出这里有两步：一是先设 $x<0$，拿 $-x$ 去套 $x>0$ 时的式子，学生分不清两个 $x$ 的范围不同；二是奇函数带来整体的负号。

## 史料（核过）

- 弗雷格 1879 年《概念文字》：第一次把“对每一个”（量词）写成严格的记号。今天的 $\forall$ 是后人定的写法。
- 弗雷格 1891 年 1 月 9 日在耶拿的演讲《函数与概念》：把 $2x^3+x$ 写成 $2\cdot(\;)^3+(\;)$，说函数本身是“不饱和的”，有空位，放进东西才完整；$x$ 只是标出空位。

## 顺序（同第 1 章）

1. **按习惯作答**：写出 $x<0$ 时的式子，记下来。
2. **拿昨天的结果当裁判**：把 $x=-1$ 代进他写的式子，和第 1 章推出的 $f(-1)=-3$ 对。照抄 $x^2+2x$ 的，会得到 $-1$，正是第 1 章那个错答案。
3. **说出怎么想的**，再问“两个 $x$ 是不是同一个”，以及“同一个字母就是同一个数”这想法从哪来。剧情先承认：初中解方程时，$x$ 是“某一个”，这想法没错过。
4. **弗雷格**：栞带来《函数与概念》，黑板上写 $2\cdot(\;)^3+(\;)$。题目式子 $=$ 空位只收正数的 $f(\square)=\square^2+2\square$。字母分两种：空位、某一个。
5. **正确的思考**（11-13 用户补：要说明奇函数对定义域里一切 $x$ 成立；用在负数 $x$ 上时，$f(-x)$ 括号里是正数、$f(x)$ 括号里是负数，不影响使用定义。剧情里把两条规定并排写：规定①空位只收正数，规定②奇函数空位收定义域里每一个数）：手里的 $x$（某一个负数）放不进空位 → 放 $-x$（正数，差一个负号，能用奇函数接回来）→ $f(-x)=x^2-2x$ → 奇函数 $f(x)=-f(-x)=-x^2+2x$ → 用 $x=-1$、$x=-2$ 对一对。
6. **题目**：奇函数 $x^2-3x$、偶函数 $2x+1$ 各求 $x<0$ 的式子；六道“这个字母是空位还是某一个”（含奇函数定义里的 $x$），最后一道是分类讨论的来历（$a$ 是拿定的但不知道是几）。
7. **回头看**：原样摆出他一开始写的式子和三个选择，按他写的式子类型给一段话。
8. **钩子**：美羽“见过那么多怎么还会错”→ 罗素那只鸡。

## 预判：差生会在哪儿错、哪儿不懂，各自怎么接

| 预判 | 在哪儿接 |
|---|---|
| 照抄 $x^2+2x$ | 用 $x=-1$ 对出 $-1$，夏海认出“那是昨天的错答案” |
| 整个式子前面加负号（$-x^2-2x$） | 回头看点明：负号想到了，漏了“先把 $-x$ 放进空位” |
| 只算到 $f(-x)$（$x^2-2x$） | 剧情和题目里都专门说“这还是 $f(-x)$” |
| 以为两个 $x$ 是同一个 | 栞、夏海对话：一个只能正、一个只能负，不可能是同一个数 |
| 以为题目式子里的 $x$ 要求出来 | 选错时夏海：“它从头到尾没让我求 $x$” |
| 以为“设 $x<0$”之后 $x$ 还能随便换 | 选错时静：“不能这一行是 $-1$、下一行变成 $-7$” |
| 想把 $x$ 直接放进空位 | 回到第 1 章的小前提 |
| 放 $x^2$（也是正数） | 栞：能放进去，但和 $f(x)$ 搭不上；灯：奇函数只管差一个负号的两个数 |
| $(-x)^2$ 写成 $-x^2$；$2\cdot(-x)$ 丢负号 | 各有专门一句 |
| 负号只变一项（$-x^2-2x$） | “负号要管括号里每一项” |
| 以为奇函数的 $x$ 也得是正数，不敢把负数 $x$ 放进去 | 黑板并排两条规定；选错时静：“只收正数的是规定①，规定②不挑” |
| 以为 $f(-x)$ 括号里是负数、$f(x)$ 括号里是正数 | 专门一问；静：“带负号不一定是负数，$x=-5$ 时 $-x=5$” |
| 一边正一边负，觉得“这样不行吧” | 美羽替他问出来；静：“规定②说的是对每一个数，放负数照样成立” |
| 偶函数也加负号 | “偶函数没有负号，负号是奇函数的” |
| 以为 $-x$ 是负数 | 题目第 ① 步专门问，答错给 $x=-5$ 的例子 |
| 分不清参数 $a$ 的身份 | 迁移第 5 题：$a$ 是“某一个但不知道是几”，所以要分类讨论 |

## 定位（11-13 补）

学生注意力差、容易忘了自己在哪个问题里：顶上“你在这儿”条随剧情走到第几步；对话框上方一行写“第几步 · 要：……”；讲完弗雷格之后插一问“说回题目：我们要求的是什么？”。
