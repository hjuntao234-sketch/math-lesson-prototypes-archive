# 主线第 1 章 · 规定管不到我（亚里士多德）· 设计与预判

用户 2026-11-13：“要让他们认真的考虑自己在思考什么，他们的思考是从哪来的，然后再揭示正确的思考是什么。当然你得预判差生会在哪些地方思考出现差错或者不能理解。我们依旧以那道题做一个小样，先是剧情，后是题目”。

## 顺序

1. **先按习惯作答。** 夏海让玩家“先别想太多，按平时的习惯写” $f(-1)$。答案记下来，最后拿来对照。
2. **说出脑子里怎么走的。** 有村静问“一步一步说给我听”，四个选项，明说“不用挑对的”。
3. **这习惯从哪来。** 多数人会选“初中一直这么做”。剧情接住它：初中的 $y=2x+1$ 什么数都管，所以“代进去”从没错过，也就没人练过“先看它挑不挑”。**先承认这个习惯在初中是对的，再指出它在这儿缺了什么。**
4. **亚里士多德。** 黑羽灯把《工具论》当“古代兵器”拿来，念出“所有人都会死……”。美羽说是废话，于是换成“所有田径部的人早上六点训练，美羽是回家部”，结论推不出来。
5. **用三段论重写这道题。** 黑板上三行：大前提（换成大白话“只要放进来的数大于 0”）、小前提（$-1>0$？✗）、结论（这条规定对 $f(-1)$ 什么也说不出来）。“你脑子里那一步‘代进去’，其实是一个三段论，只是跳过了中间那句：小前提。”
6. **揭示正确的思考：换一条大前提。** 奇函数“对每一个数 $x$，$f(-x)=-f(x)$”，它不挑数；$x$ 取 $1$；再回到第一条规定查 $1>0$ ✓。两个三段论走完才得 $-3$。
7. **题目。** 两道自己走（奇函数 $f(-2)$、偶函数 $f(-3)$），每道先查小前提再换规定；四道换地方用（不同章节的规定，只判断能不能推出）。
8. **回头看。** 把玩家一开始的答案、自己选的“脑子里怎么走”“从哪来”原样摆出来，按他的选项给一段话。最后一句：用一条规定之前，先查小前提。
9. **钩子。** 栞问“要是问 $x<0$ 时的式子，那个 $x$ 又是谁？”，引出下一章弗雷格。

## 预判：差生会在哪儿错、哪儿不懂，各自怎么接

| 预判 | 在哪儿接 |
|---|---|
| 把“当 $x>0$ 时”当装饰 | 夏海、美羽说出来；“初中和这题最要紧的不同”一问 |
| 以为差别在长相（一次、二次） | 选错时静说“差别不在长相” |
| 嫌三段论是废话 | 美羽替他说出来，马上换成推不出的田径部例子 |
| 以为推不出是因为规定错了 | 选错时夏海说“规定没错，只是管不到” |
| 把“推不出”当成“推出相反”（否定前件） | 静：“是说不出来，不是一定不六点起”；迁移第 4 题专门考（$(-2)^2>0$ 本身对，但那条规定推不出） |
| 数轴不熟，看不出 $-1$ 不满足 $x>0$ | 栞画数轴：$-1$ 在 $0$ 左边，左边的数都比 $0$ 小 |
| 奇偶混淆（以为奇函数左右对称） | 选错时静讲清；第 2 道偶函数题加了负号会被点出来 |
| 以为“奇函数”就是 $f(-1)=-1$ | 选错时灯：“它说的是关系，不是某一个值” |
| 奇函数的 $x$ 取 $-1$ | 静：“也对，可绕了一圈”，引到 $x=1$ |
| 忘负号（写 $3$）、负号只管一项（写 $1$）、$-(-2)$ 写成 $-2$ | 各有专门一句 |
| 在“换成正数之后”又把负数代进去 | 第 1 道：“这是把 $-2$ 代进去了，要算的是 $f(2)$” |
| 把“大前提、小前提”背成新名词 | 名词只出现一次，之后一律用大白话：“规定管谁”“我在不在里面” |
| 只学会“奇函数题”，换个地方不会用 | 迁移四题：基本不等式、平方、绝对值 |

## 定位（11-13 补）

学生注意力差、容易忘了自己在哪个问题里：顶上“你在这儿”条随剧情走到第几步；对话框上方一行写“第几步 · 要：……”；讲完田径部之后插一问“说回题目：我们要求的是什么？”。
