# 验收评分表：怎样算“和小样同一个样子”

由审读者（Claude）逐项打分，不由作者自评定分。作者的自评只作参考。

## 硬线（任何一条不过，整份不过）

- H1 **数学零错**：验算脚本从题面独立重算，覆盖页面里出现的每个数、每个预判错答的值、每个反例。审读者另行抽查。
- H2 **页面零报错**：一直卡、全对两条走查都能从头走到尾，原有走查不受影响。
- H3 **没改别人的文件**：除教室入口一行外，引擎和已有章节一字不改。
- H4 **学生端无 API、无密钥**。

## 打分（每项 0 / 1 / 2，满分 26）

| # | 项目 | 2 分的样子 |
|---|---|---|
| 1 | 先暴露想法 | 先按习惯作答，再选“脑子里怎么走的”“从哪来”；剧情先承认旧习惯的合理之处 |
| 2 | 揭示正确思考 | 有一个讲清“为什么”的哲学、逻辑观念或方法，史料准确，讲完马上用在题上 |
| 3 | 四问板 | 关键步写出要、有、差、补，“差”说清为什么不能直接拿 |
| 4 | 阶梯题 | 至少 2 处，放在最难步骤之前，逐级上去，用具体的数或简单函数 |
| 5 | 探究 | 至少 1 个能动手的（拖、点、选点对），页面当场判定；有“先猜后证”或“找反例”；不是选择题 |
| 6 | 构造 | 需要“取一个数”的地方，从落点倒推：四问板 → 拖着试 → 换数自己算 → 写成字母 |
| 7 | 预判 | 至少 10 条，写成表，每条有专门回应，而且在页面里真的接住了 |
| 8 | 拆细 | 至少 6 处，至少 2 处两层，先具体的数；标题是学生能懂的问题 |
| 9 | 注意力 | 定位条每步更新、“要”随问更新；绕远后拉回至少 3 次 |
| 10 | 方法卡 | 用到就发，写“看到、就做、不灵”；章末方法本；不先给名词 |
| 11 | 语言 | 日常整句；没有生活比喻代替逻辑；一个概念一个说法；从小学起点写 |
| 12 | 分节和记忆 | 题长就分节，每节有“上回说到”；回头看原样摆出学生一开始的答案和选择 |
| 13 | 换个地方用 | 有换数、换条件的题，或换章节的判断题 |

## 通过线

硬线全过，且总分 ≥ 20、没有 0 分项，就算“同一个样子”。通过线由用户定，这是建议值。
