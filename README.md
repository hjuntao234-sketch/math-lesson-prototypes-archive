# 数学网页课 · 废案存档

> **废案。** 这里存的是已经停掉的实验原型，不再维护，放上来只作记录，说不定有人能从中找到灵感。
> *Abandoned prototypes (archived, not maintained): a draft "math lesson page" skill for AI, a story-driven math card game, and a map of math-game ideas.*

这些东西都是给高中数学后进生做的：想让学生在网页上一步一步把一道题想明白，而不是只看答案。

## 里面有什么

### 1. `数学网页课skill/`：让 AI 按一道题做一节带剧情的互动网页课

- `skill草稿-R2/`：skill 草稿第 2 版（2026-11-14）。`SKILL.md` 是入口，`references/` 里是方法、页面规矩、引擎接口、验收评分表和范例索引。`skill草稿-R1/` 是第 1 版，留作对照。
- `范例小样-R18/`：范例《放学后的补习》。学生给五个女生讲题，主线是哲学和逻辑科普（第 1 章亚里士多德、第 2 章弗雷格），另有一章压力测试。
  - 打开：双击 `index.html`。公式和字体从网上加载，要联网。
  - 验算：`python3 verify.py`、`python3 stress_verify.py`。
  - 走查（无头 Chrome，要装 Node 和 Google Chrome）：`node tools/ch1.cjs <本文件夹的绝对路径> <截图文件夹>`，`ch2`、`drill`、`walk`、`stress` 同样用法。
- `迁移测试/`：两次让另一个 AI（GPT）照这份 skill 独立做一节课。第 1 次（椭圆）21/26，第 2 次（随机变量混检）23/24。
  - 两份 `*-审读.md` 是审读结果；`任务稿/` 是发给 GPT 的任务；`GPT产出/` 是 GPT 交回的整份小样副本（新章节都在 `ch4.js`）；`回执/` 是 GPT 的交付说明；`GPT验收记录/` 是 GPT 自己走查时的截图和日志。
  - `GPT产出/` 里旧走查脚本引用的 `cdp.cjs` 路径指向原工作目录，在这里跑不起来；要走查，改成 `范例小样-R18/tools/cdp.cjs`。
- `清单/`：范例各版本（R1—R18）和 skill 草稿的 SHA-256 清单，只是版本记录。
- `立绘-第1阶段/`：范例里五个女生的立绘。五张平静立绘、夏海四张表情，各配一张透明头像。
  - `成品/` 是统一比例尺的 1024×1536 全身图和 512×512 头像；`原图/` 是出图工具的原始输出；`检查/` 是阵容、剪影盲测、头像盲测等检查图；`tools/` 是后期脚本。
  - `任务稿-第1阶段.md` 是外形设计和出图要求，`审读-第1阶段.md` 是审读结果（盲测 10/10，通过）。`出图记录.md` 逐张记了提示词和用的工具。

**停在哪**：草稿 R2，还没打包成能直接安装的 skill。立绘只做了第 1 阶段，还没接进范例页面，范例里的头像仍是一个字的圆圈；其余四人的表情没有做。

### 2. `卡牌游戏/`：带剧情的数学卡牌策略游戏（原名《罗盘指挥官》）

最后一版，停在 2026-11-13 的“纸与守卫”改版：拿掉了牌和心力，改成左边纸上逐行写、右边守卫逐行验。旧的卡牌战斗代码还在，但走不到。

- 打开：`v6/dist/index.html#卡牌` 是试玩章地图，右下角“开发菜单”能进各关样板。
  - `v6/dist/toy.html`：拖数原型；
  - `v6/dist/teacher.html`：老师端判读。
  - 都要联网加载公式和字体。
- 源码在 `v6/`，关卡数据在 `关卡/`，剧本在 `剧本/`，设定和设计文档在 `设定集/`，压缩后的图片在 `素材/`。
- 设计的来龙去脉，先看 `设定集/总监决定汇总.md` 和 `设定集/纸与守卫-定稿说明.md`。

其余全部过程材料也都在这里：

| 目录 | 内容 |
|---|---|
| `v1/`—`v4/`、`旁支/` | 2026-11-04—11-05 的早期版本，以及没采用的几何特效分支 |
| `art/`、`assets/`、`grok/` | 最早的占位图、背景音乐、给 Grok 的出图／配乐／剧情提示词 |
| `gemini/` | 给 Gemini 的提示词，以及收回来的立绘、背景、剧情稿和配乐（`gemini/回收/`） |
| `立绘-GPT/` | GPT 分阶段画的 62 张人物立绘和守卫部件：原图、抠图、检查图、后期脚本、审读附图 |
| `配音/` | 序章配音试做（几种 AI 语音的试镜和英文正式版）、台词表、声音设定和合成脚本 |
| `任务稿与审读/` | 发给 GPT 的任务稿、审读意见、交接说明和 SHA-256 清单；`GPT-Astra工作区/` 是“纸与守卫”抽象函数样品的 GPT 原件 |
| `快照/` | 2026-11-09、11-12、11-13 三个时间点的整包快照（zip） |

**没有放进来的**：
- 早期版本当时是从另一个还在做的项目里抽题目数据来生成的。那份数据和用它生成的页面（`data-inequality.json`、`extract.py`、`v2/index-v2-built.html`、根目录旧 `index.html`、`v6/dist/game.html` 旧地图版）没有公开，给 Gemini 写剧本用的“学习剧情材料”也一样。所以 `v2`—`v4` 和 `v6/build_game.py` 不能重新构建，只能看代码。
- 配音工具依赖的第三方 Python 包（`vendor/`）、几张带个人账号信息的网页截图。
- 文件里原来的本机路径和用户名已经换成 `~`、`user`。

**为什么停**：做成游戏限制太多，玩起来也不够自然。2026-11-14 改做上面那份 skill，后来 skill 也停在草稿。

### 3. `游戏灵感地图/`：高中数学游戏灵感地图

一页构思图（2026-11-14，GPT 做）：从各单元的数学内容，经过“换一种表示”“调参看变化”“检查边界”等思维动作，连到可能的游戏玩法，每个单元附一条易卡点。直接打开 `map-preview.html`，要联网加载字体和图标；`check-map.cjs` 是 GPT 当时的显示检查脚本。

## AI 生成内容标识

- **文字和代码**：在作者指导下，由 AI（Anthropic Claude、OpenAI GPT／Codex）生成，经作者审定和修改。
- **图片**：全部由 AI 生成（OpenAI 图像模型、Google Gemini 等），经人工挑选、抠图和压缩。
- **背景音乐**：AI 生成（按记录是用 Google Gemini 生成后收回的，见 `gemini/02-配乐.md`、`gemini/回收/`），只做过响度和首尾处理。
- **配音**：全部是 AI 语音合成（OpenAI 语音模型、Google AI Studio 的 Gemini TTS），不是真人录音。
- **音效**：在网页里用程序实时合成。
