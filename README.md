# 数学网页课 · 废案存档

> **废案。** 这里存的是两套已经停掉的实验原型，不再维护，放上来只作记录。
> *Abandoned prototypes (archived, not maintained): a draft "math lesson page" skill for AI, and a story-driven math card game.*

两套东西都是给高中数学后进生做的：想让学生在网页上一步一步把一道题想明白，而不是只看答案。

## 里面有什么

### 1. `数学网页课skill/`：让 AI 按一道题做一节带剧情的互动网页课

- `skill草稿-R2/`：skill 草稿第 2 版（2026-11-14）。`SKILL.md` 是入口，`references/` 里是方法、页面规矩、引擎接口、验收评分表和范例索引。
- `范例小样-R18/`：范例《放学后的补习》。学生给五个女生讲题，主线是哲学和逻辑科普（第 1 章亚里士多德、第 2 章弗雷格），另有一章压力测试。
  - 打开：双击 `index.html`。公式和字体从网上加载，要联网。
  - 验算：`python3 verify.py`、`python3 stress_verify.py`。
  - 走查（无头 Chrome，要装 Node 和 Google Chrome）：`node tools/ch1.cjs <本文件夹的绝对路径> <截图文件夹>`，`ch2`、`drill`、`walk`、`stress` 同样用法。
- `迁移测试/`：两次让另一个 AI 照这份 skill 独立做一节课的审读记录。第 1 次（椭圆）21/26，第 2 次（随机变量混检）23/24。

**停在哪**：草稿 R2，还没打包成能直接安装的 skill；人物立绘还是一个字的圆圈。

### 2. `卡牌游戏/`：罗盘冒险模式（带剧情的数学卡牌策略游戏）

最后一版，停在 2026-11-13 的“纸与守卫”改版：拿掉了牌和心力，改成左边纸上逐行写、右边守卫逐行验。旧的卡牌战斗代码还在，但走不到。

- 打开：`v6/dist/index.html#卡牌` 是试玩章地图，右下角“开发菜单”能进各关样板。
  - `v6/dist/game.html`：更早的地图版（旧卡牌系统）；
  - `v6/dist/toy.html`：拖数原型；
  - `v6/dist/teacher.html`：老师端判读。
  - 都要联网加载公式和字体。
- 源码在 `v6/`，关卡数据在 `关卡/`，剧本在 `剧本/`，设定和设计文档在 `设定集/`，图片在 `素材/`。
- 设计的来龙去脉，先看 `设定集/总监决定汇总.md` 和 `设定集/纸与守卫-定稿说明.md`。

**没有放进来的**：原始大图（只留了压缩后的 webp）、早期草图、配音、背景音乐（来源没有记全），以及 v1—v4 的旧版本。所以重新构建要缺素材，直接打开 `v6/dist/` 里的页面就能玩。

**为什么停**：做成游戏限制太多，玩起来也不够自然。2026-11-14 改做上面那份 skill，后来 skill 也停在草稿。

## AI 生成内容标识

- **文字和代码**：在作者指导下，由 AI（Anthropic Claude、OpenAI GPT／Codex）生成，经作者审定和修改。
- **图片**：全部由 AI 生成（OpenAI 图像模型、Google Gemini），经人工挑选、抠图和压缩。
- **音效**：在网页里用程序实时合成。
