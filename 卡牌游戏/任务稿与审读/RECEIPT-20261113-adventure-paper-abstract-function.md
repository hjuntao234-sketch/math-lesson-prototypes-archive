# 抽象函数样品回执 · 2026-11-13

## 我理解的这个游戏

纸是攻击，守卫是题目本身。手里先碰到一个会回应的对象，猜它的脾气；落笔后，每一个有根据的结论都让它少藏一点。错了，它拿具体对象反击；队友只替你照亮一个角落。和做题网页的区别，不在答对后放动画，而在你写出的数学改变了眼前同一个对象。这道题最该爽的一下，是自己证明“递增”后，终于有资格把两个函数值的比较压回输入端：雾里的守卫被拉到熟悉的二次不等式上，最后连端点那句嘴硬也被自己代数打穿。

## 三个难处与对 Claude 推演的调整

**验真与验推理分开。** 等式做精确有理系数归一化，证明行还检查已证前提、实际代入及所引条件。只写真话 f(0)=0、依据只写 f(1)=2，会被抓住；所引单一条件的常函数证人明确标注“不是本题全部条件的反例”。未识别表达不扣血。

**真值唯一。** 加法性先给零值及奇性；正性配合作差给严格递增；有理数上 f(q)=cq，再由有理数夹逼得到所有实数上 f(x)=cx。后台用它算图和反例，不能让学生凭后台式子跳过证明。

**去掉 f 要有来路。** 该行依赖纸上已证递增、已求出的右端函数值以及合并行；只有“加法性”不能过，不等号方向也单独检查。逆序函数 g(t)=-t 仅用于说明单靠加法性不够，绝不冒充本题反例。

推翻了“本题有多种满足全部条件的函数”的设想；保留雾中探点，增加明确的“断链”反馈。不能把所有错误都包装成同一种数学反例：这一点是骨架跨到证明题后必须承认的边界。

## 实现与回归

入口仍为 `v6/dist/index.html#卡牌`；新增 `#抽象函数` 与营地节点。`dark.js` 是共用纸面/战斗流程；`paper-ellipse.js`、`paper-abstract.js` 为题型适配器，`abstract-core.js` 是有限证明核。无新增玩法系统、学生端 API 或真实密钥依赖。

独立验算：亮灯 f(0)=0、f(3)=6、解集 (-3,1)；关灯 f(1)=3、右边24，f(3)=9、f(8)=24、解集 (-4,2)。两种边界均排除。

`bash v6/tools/test/run_all.sh --static-only` 退出0：原数据检查、构建、旧假 API 测试、88条证明核断言、共用纸面模拟事件流程、24种椭圆画布指令对照通过。椭圆两份题目 JSON 不变，原真值/逐步验证逻辑除入口函数改名外逐字一致。只有一个 gpt-6.1-sol（medium）走查，问题已差量修复。

**不是完整 run_all 放行。** 新增 `abstract_t.cjs` 真实鼠标键盘脚本（正路、反例、断链、去 f、关灯、失败续写）并纳入全回归，但本轮没有执行任何浏览器测试。用户明确把亲手试玩改由自己验收；模拟 DOM/Canvas 不等于浏览器、真人或课堂证据。“是同一个游戏”尚无结论。

开工 SHA 清单全过；改前 v6/、关卡/ 在 `立绘-GPT/抽象函数样品/改前/`。日志与变更哈希在同级 `验收/`。

## 我最不满意的一处

为了离线检查推理，这张纸仍有明显的固定路线和表达习惯；学生想到另一条合法证明，可能被要求拆回当前步骤。眼下它证明的是“共用流程能承载第二类数学对象”，尚未证明“学生感觉自然”。到此停工，等用户先打椭圆第一只、再打抽象函数。其他量产任务继续暂停。
