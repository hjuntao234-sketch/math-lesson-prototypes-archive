## 2. 通用规格（每只守卫都照这个）

- **画布**：1200×1100 透明。图层全部同尺寸、同坐标系，叠起来就是完整守卫。PNG 原图放 `立绘-GPT/批2a/`，转成 600×550 webp（`-q 82 -alpha_q 95`）放进 `素材/守卫/<id>/`。
- **画风**：和 `素材/守卫/p2/` 一样的雾做的身体，可爱、不吓人，圆头、两只琥珀色发光眼睛、没有嘴，没有文字、数字和字母。
- **描边**：浓雾背景上白色的守卫容易看不见。原画要带一圈很淡的深色描边或阴影，在 `v3/assets/bg-path.webp` 上也分得出来。
- **朝向**：守卫站在画面右边，脸和手朝左（朝着左边的队友）。
- **坐标**（`pivots.json`，画布像素）：
  - 必须有：`canvas`、`head.center`、`head.r`、`ground.y`。引擎用头中心和地面线摆位置。
  - `eyes` 要有 `left`、`right`。
  - 文中列出的每个点都要有。点要落在那一块图的视觉中心，学生要点得中。
  - 要沿某一点收短、伸长的图层（只能横向缩放），写 `shoulder`，表示从哪儿缩。
- **图层清单**（`guard.json`）：
  - `名`、`原型`；
  - `order`：叠放顺序，从下到上；
  - `hidden`：开局藏着的层。
  
  藏着的层要和显着的层**严丝合缝地替换**：同一个位置、同样大小，换上去不跳。
- **检查图**（每只守卫一张，放 `立绘-GPT/批2a/检查/`）：
  - 在 `bg-path.webp` 上，把每种状态并排放（完整、每个替换状态、显出隐藏层的状态）；

## 3. A：五种守卫原型

每种一个文件夹，名字照下表；以后各张卡的道具文件夹写 `"base": "<原型 id>"` 继承它。

### 3.1 `balance` 天平守卫（a 路：比大小、范围，卡 1—5）

- **样子**：雾做的身体当立柱，头顶横着一根木梁，两端各挂一个托盘。两个托盘就是要比的两个式子。
- **图层**：

  | 图层 | 开局 | 说明 |
  |---|---|---|
  | `body` | 显 | 立柱身体和头 |
  | `eyes` | 显 | 两只眼和光晕 |
  | `scale-level` | 显 | 横梁放平，两个托盘一样高 |
  | `scale-left-down` | 藏 | 左盘低（左边重） |
  | `scale-right-down` | 藏 | 右盘低（右边重） |
  | `scale-merged` | 藏 | 两个托盘合成一个大盘挂在中间（作差：两个式子变成一个差） |

- **点**：每个 `scale-*` 写 `pan-left`、`pan-right` 的中心（`scale-merged` 只写 `pan`）；`body` 写 `post`（立柱中段）；外加 `head`、`ground`、`eyes`。
- **数学含义**：比大小时托盘往哪边沉；作差时两个托盘合成一个，只看这一个盘里是正是负；方向判断（取倒数、平方、乘负数）时，学生要猜梁会往哪边倒。

### 3.2 `arch` 拱桥守卫（c 路：一元二次不等式，卡 14—18）

- **样子**：身体弯成一座雾做的拱（抛物线），两只脚踩在地上一条横线上。那条横线就是 x 轴，脚踩的两个点就是两个根。
- **图层**：

  | 图层 | 开局 | 说明 |
  |---|---|---|
  | `axis` | 显 | 地上那条横线（x 轴），左右都要长出身体以外 |
  | `arch-down` | 显 | 开口向下的拱，两脚落在 axis 上 |
  | `arch-up` | 藏 | 开口向上的 U 形，两脚落在**同样两个点**，底沉到线下 |
  | `arch-up-touch` | 藏 | 开口向上，底点刚好碰到 axis（相切，只有一个点） |
  | `arch-up-float` | 藏 | 开口向上，整条悬在 axis 上方，不碰（无根） |
  | `eyes-down`、`eyes-up`、`eyes-touch`、`eyes-float` | 只显和身体配对的那一个 | 每种形状的眼睛单独一层，跟着形状走 |
  | `flag-left`、`flag-right` | 藏 | 插在两个根上的小旗（没有字） |
  | `shade-between` | 藏 | 两根之间的 axis 一段涂亮（解集在中间） |
  | `shade-outside` | 藏 | 两根外面两段涂亮（解集在两边） |

- **点**：
  - `arch-down` 和 `arch-up` 写 `foot-left`、`foot-right`（两种开口必须是同一对坐标）和 `top`（顶点或底点）；
  - `arch-up-touch` 写 `touch`；`arch-up-float` 写 `bottom`；
  - `flag-left`、`flag-right` 写 `center`；`shade-between`、`shade-outside` 写 `center`；
  - 外加 `head`（取拱顶附近的头）、`ground`（`y` 就是 axis 的高度）、`eyes`。

  `head.center` 定在 `arch-down` 的头上。
- **数学含义**：开口方向、两根、相切和悬空（判别式）、解集在两根之间还是两边。

### 3.3 `siege` 攻城守卫（d 路：恒成立和参数，卡 19—25）

- **样子**：一段雾做的矮城墙，墙头是一条起伏的曲线，**有一处最低**；守卫趴在墙后探出头，三只手从墙上不同的方向往外推。
- **图层**：

  | 图层 | 开局 | 说明 |
  |---|---|---|
  | `wall` | 显 | 城墙，墙头曲线有一个明显的最低处 |
  | `wall-raised` | 藏 | 同一段墙整体抬高一截（参数变了，最低处也过线了） |
  | `body` | 显 | 墙后的守卫身体和头 |
  | `eyes` | 显 | |
  | `arm-a`、`arm-b`、`arm-c` | 显 | 三只手，从左上、正左、左下三个方向往外推 |
  | `low-gap` | 藏 | 最低处那一块发亮的缺口 |
  | `line` | 显 | 墙前地上的一条横线：墙头要整段高过它才算守住 |
  | `flag` | 藏 | 插在最低处的小旗：最低处也过线了 |

- **点**：
  - `wall` 和 `wall-raised` 写 `low`（最低处），`wall` 再写 `left`、`right`（两头）；
  - 每只手写 `shoulder`、`fist`；`low-gap`、`flag` 写 `center`；
  - 外加 `head`、`ground`、`eyes`。`line` 的高度写成 `line.y`。
- **数学含义**：“对一切 x 都成立”就是整段墙都高过那条线，只要最低处过线就行；分离参数就是看最低处在哪。

### 3.4 `zigzag` 折线守卫（绝对值，卡 26—29）

- **样子**：身体是三段雾连成的折线，像一道弯折的闪电或一条弹簧；两个关节是亮点（分界点）。脚下一条带刻度的数轴（只有刻度线，不写数）。
- **图层**：

  | 图层 | 开局 | 说明 |
  |---|---|---|
  | `numline` | 显 | 数轴和刻度 |
  | `seg-left`、`seg-mid`、`seg-right` | 显 | 三段折线 |
  | `seg-mid-flat` | 藏 | 中间一段放平（距离和在一段上都最小） |
  | `joint-1`、`joint-2` | 显 | 两个关节亮点 |
  | `eyes` | 显 | 眼睛长在 `seg-right` 的顶端（这一段最高，头也画在这里，不单独分层） |

- **点**：每段写 `center`；`joint-1`、`joint-2` 写 `center`；`seg-mid-flat` 写 `center`；外加 `head`、`ground`（数轴高度）、`eyes`。两个关节的横坐标要正好对着数轴上的两个刻度。
- **数学含义**：零点分段，分界点就是关节；距离和最小值在中间那一段。

### 3.5 `mirror` 镜子守卫（证明和强基，卡 30—35）

- **样子**：守卫两只手抱着一面落地的椭圆镜子。镜子有正反两面。
- **图层**：

  | 图层 | 开局 | 说明 |
  |---|---|---|
  | `body` | 显 | |
  | `eyes` | 显 | |
  | `arm-left`、`arm-right` | 显 | 抱镜子的两只手 |
  | `mirror-front` | 显 | 镜子正面：镜面里是一团模糊的雾 |
  | `mirror-back` | 藏 | 翻过来的背面：木框和几道刻痕（反证、换个方向看） |
  | `mirror-clear` | 藏 | 正面擦亮了，镜面里映出守卫自己（证完了） |
  | `crack` | 藏 | 镜面一道裂纹（找到反例，原命题不成立） |

- **点**：`mirror-front`、`mirror-back`、`mirror-clear` 写 `center`；两只手写 `shoulder`、`fist`；外加 `head`、`ground`、`eyes`。
