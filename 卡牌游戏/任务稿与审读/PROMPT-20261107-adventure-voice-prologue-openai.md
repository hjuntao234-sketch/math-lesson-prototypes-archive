## 2. 密钥（最要紧）

- 脚本只能从两个地方拿密钥，拿到了只放在内存里：
  1. 环境变量 `OPENAI_API_KEY`；
  2. 没有的话，读 macOS 钥匙串里服务名为 `compass-openai-tts` 的条目（`security find-generic-password -s compass-openai-tts -w`）。
- 两处都没有，就停下，请用户**自己**设置，你不要代设。用户可以二选一：在钥匙串访问里新建这个条目，或者在自己的终端里运行下面这句（运行后会提示输入密钥，命令历史里不会留下密钥）：

  ```bash
  security add-generic-password -a "$USER" -s compass-openai-tts -w
  ```

- 不要让用户把密钥贴进对话。用户如果贴了，不要用，提醒用户去 OpenAI 后台作废这把密钥、重新生成一把。
- 密钥不许出现在任何文件、日志、进度、截图、命令行参数或报错输出里。打印请求信息时要把请求头去掉。
- 不建 `.env` 文件，也不把密钥写进任何配置文件。
- 沙箱要是不让连 `api.openai.com`，就停下告诉用户，由用户决定放不放行。不要绕开沙箱。

## 3. 先查模型和声音

先读 OpenAI 官方文档的语音生成（text-to-speech）部分，确认下面三件事：
- 现在推荐哪个模型；
- 能不能用文字指定说话的语气（instructions 一类的参数）；
- 有哪些预设声音。

选一个能指定语气、中文念得好的模型。进度文件里要记下：模型名、文档网址、查看日期，以及官方价目表上这个模型的计价方式。

只用官方预设的声音。**不克隆任何人的声音，不模仿真实的声优、主播或明星。**

## 4. 第一步：试镜（24 条，做完就停）

1. 四个人的声音描述在 `配音/声音设定.md` 里，中英文各一段。把英文那段当作这个人的语气说明（instructions），每句再接上台词表里这一句的“表演”。
2. 每个人挑 3 个候选预设声音：
   - 诺曼是男生，用偏男声的声音；三个女生用偏女声的声音。
   - 四个人的第一候选不要重复。
3. 台词表里 `"试镜": true` 的 8 句（每人 2 句），每句用这个人的 3 个候选各念一遍，共 24 条。念的是“念法”字段，不是“原文”。
4. 输出：
   - 音频放在 `配音/序章/试镜/`，文件名写成 `人-句号-声音名.mp3`。
   - 做一页 `配音/序章/试镜.html`：
     - 按人分四组；每条标明候选声音名，并附一个播放器。
     - 每组顶上写这个人的一句话描述，从声音设定里抄。
     - 页面底部写“配音为 AI 生成”。
     - 只用本地文件，双击能打开，不引用任何外部网址。
5. **停下**，请用户听试镜页，每人选一个声音，也可以说“都不行，换一批”。
   - 用户的原话、日期写进 `配音/序章/选声.md`，照原话抄，不要改写。
   - 用户要换一批的，最多再试一轮（每人 3 个新候选），还不行就停下报告。

## 5. 第二步：全配 69 句（用户选好以后才做）

1. 按用户选的声音念全部 69 句：语气说明是这个人的英文描述加上这一句的“表演”，念的是“念法”字段。
2. 输出 mp3，文件名用台词表里的“文件”字段，放在 `配音/序章/`。
3. 用 ffmpeg 的 loudnorm 把响度统一到 −16 LUFS，峰值不超过 −1.5 dBTP。本机有 `/opt/homebrew/bin/ffmpeg`。
4. 跑 `python3 配音/check_序章台词.py --audio`：
   - 报“时长可疑”的句子，换个说法重念（比如把“表演”写得更具体）。
   - 每句最多重念 2 次，还不行就列进进度文件，不要硬凑。
5. 可选的回听检查：用 OpenAI 的语音转文字接口把每句转回文字，和“念法”对比。
   - 字差得多的，标出来、重念；重念次数照上一条算。
   - 这一项也算进第 6 节的预算。
   - 转写结果只放在本地进度文件里。
6. 做一页 `配音/序章/试听.html`：
   - 按出场顺序列出 69 句，每句显示“人、原文、播放器”，“听这里”不为空的句子要醒目标出来。
   - 顶上一个“从头连播”按钮。
   - 页面底部写“配音为 AI 生成”。
   - 只用本地文件。

## 6. 预算和次数

- 开工前按官方价目表估一次全程花费，写进进度文件。
- 试镜加全配，语音生成调用合计不超过 260 次（试镜第一轮 24 次，加换一批的 24 次，加全配 69 句各最多念 3 遍，就是 255 次）。
- 回听检查的转写调用另算，每条音频最多转写一次。
- 全部加起来，总花费按估算不超过 5 美元。
- 两条哪一条快超了，就停下报告，等用户决定。
- 不用别的付费服务，不开新的付费功能。遇到要同意条款或付款的页面，停下交给用户本人处理。
