## 4. 第三步、第四步：设计声音，念台词

### 4.1 设计 4 个声音

照 `配音/声音设定.md`：
1. 每人用“创建新的声音”（或者从预设里挑最接近的再调），描述先用中文，效果不好再试英文。
2. 每人至少出 3 个候选，各用这一句试听：
   - 塔莉：“昨天那只，就叫它小双手！一只长，一只短，好记！”
   - 雅娜：“先别急着派人。看清它身上露出来的东西。”
   - 法比娅：“……补东西用。帐篷、桥，还有题。”
   - 诺曼：“名录院派我清理原野。让开，名录第三页，乘积守卫。”
3. 按这几条挑：
   - 合不合描述；
   - 四个人放在一起能不能分得开；
   - 中文咬字清不清楚；
   - 像不像高中生（不要童声，不要老成）。
4. 挑中的保存，名字用“罗盘-塔莉”“罗盘-雅娜”“罗盘-法比娅”“罗盘-诺曼”。把描述、候选几个、为什么挑这个、保存后的名字或编号，都写进记录。
5. 每人挑中那一版的试听句也下载下来，放在 `配音/试听/`，用户先听这 4 句就能判断声音对不对。

### 4.2 念 75 句

照 `配音/p2-台词.json` 一条一条来：
- **念的是 `念法`，不是 `原文`**。念法里公式已经写成读法（“x 减一分之九”）。字母照中国数学课的读法：x、t、a、b 照常念字母，不要念成别的词。
- **一句一生成**，单人模式，用这句话的人那个声音。
- 把 `表演` 写进语气或风格提示，比如“兴奋、响亮、带着笑”。想知道这句前后在演什么，看 `剧本/战斗-p2.json`。
- 下载存成 `配音/p2/<文件>`，文件名就是 json 里的 `文件`（p2-001.wav……）。下载格式不是 WAV 的，照原格式存，改后缀，记下来。
- 自查，每句都要过：
  - 时长正常：大约每个字 0.2—0.3 秒，加上停顿。比这个长一倍、短一半，或者开头结尾有很长的空白，就重生成，最多 3 次；
  - 没有念错字，没有漏字、多字；
  - 语气对得上 `表演`。
  
  重生成过的写进记录。

## 5. 规矩（严格）

- **不碰密钥**：不新建、不复制、不显示、不保存 API 密钥。只在网页界面里操作。
- **不碰钱**：不填付款信息，不开账单，不升级付费档。弹出要付费、要绑卡的，停下告诉用户。
- **条款**：只有免费额度那一项，在用户明确说“领”以后才点同意。别的条款、权限、Cookie 提示，选最少授权的那一项；拿不准就问用户。
- **不改账号设置**，不删用户已有的任何东西（历史、声音、项目）。
- **不上传**任何真人的录音，不模仿真实的声优、主播、明星。
- **不上传学生信息。**
- **可写范围**：只许在根目录下的 `配音/` 里新建文件和目录：`配音/试听/`、`配音/p2/`、`配音/配音记录.md`、`配音/进度.md`。`配音/p2-台词.json`、`配音/声音设定.md` 不许改。别的目录一律不动，不跑 `v4/build.py`，不发布网页。
- 浏览器只开 aistudio.google.com 和它为领额度跳转的谷歌官方页面。别的网站不去。
