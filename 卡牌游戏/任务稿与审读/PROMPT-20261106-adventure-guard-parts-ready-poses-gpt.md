## 2. 守卫：披外衣的守卫（7 层）

### 2.1 长什么样

- 一只**雾做的守卫**：半透明，白里带一点灰绿，边缘是散开的雾气，下半身没有腿，像一团雾拖在地上。
- 圆圆的头，两只**琥珀色的发光眼睛**，没有嘴。要有点可爱，也有点怪，不能吓人（玩的是高中生，又是序章）。
- **两只手**从身体左侧伸出来，伸向画面左边，也就是队友那一边：
  - **长手**：从肩部伸出去很远，细长，末端是一个圆圆的雾团拳头；
  - **短手**：缩在身侧，短而粗，末端也是雾团拳头；
  - 两只手的末端拳头大小差不多，**不同的只是长短**。
- **布**：一块旧的米黄色粗布，缠在短手上，一圈一圈的，有一个松掉的布头垂下来。这块布要单独一层，掉下来以后，短手是完整的。
- 画风要和背景（`v3/assets/bg-path.webp` 那种雾中小路的厚涂背景）放在一起不突兀，也要和人物立绘的二次元赛璐璐画风搭。
- **不要任何文字、数字、符号。** 式子的标签由引擎贴。

### 2.2 分层

所有层用**同一张画布**：1200×1100，透明背景。每一层都放在它在完整守卫里的位置上，直接叠起来就是完整的守卫，不用再对位。

| 文件 | 内容 | 引擎会怎么动它 |
|---|---|---|
| `body.png` | 身体和头，不含两只手、不含眼睛的发光 | 上下慢慢浮动；最后整只淡出散成雾 |
| `eyes.png` | 两只眼睛和眼睛周围的光晕 | 一闪一闪；被打中时眯一下 |
| `arm-long.png` | 长手，从肩到拳头 | 以肩为轴转动、沿手臂方向缩放 |
| `arm-short.png` | 短手，从肩到拳头，**完整的、不带布** | 同上 |
| `cloth.png` | 缠在短手上的布，只有布 | 布掉下来：往下飘、转、淡出 |
| `arm-long-equal.png` | 长手**收短**到“一样长”的样子 | 取等时换上 |
| `arm-short-equal.png` | 短手**伸长**到“一样长”的样子 | 取等时换上 |

- 后两张是“两只手一样长”时的样子。长手收、短手伸，最后两只手长度相同、姿势对称。直接画出来，不靠引擎硬拉。
- 两只手画得**尽量直**、粗细均匀，这样引擎沿手臂缩放时不会变形太厉害。
- 层和层相接的地方（肩膀和身体）要有雾气重叠，单独移动一层时不会露出硬边或空洞。

### 2.3 轴心记录

交一份 `pivots.json`，写各层的关键点，坐标按 1200×1100 画布：

```json
{
  "canvas": [1200, 1100],
  "arm-long":  {"shoulder": [x, y], "fist": [x, y]},
  "arm-short": {"shoulder": [x, y], "fist": [x, y]},
  "arm-long-equal":  {"shoulder": [x, y], "fist": [x, y]},
  "arm-short-equal": {"shoulder": [x, y], "fist": [x, y]},
  "cloth": {"center": [x, y]},
  "eyes": {"left": [x, y], "right": [x, y]},
  "head": {"center": [x, y], "r": 0},
  "ground": {"y": 0}
}
```

`ground.y` 是守卫底部的雾拖在地上的那条线，引擎用它对齐队友脚下那条线。

## 5. 自查

1. **叠得上**：前 5 层直接叠起来就是完整守卫，层与层之间没有缝、没有空洞、没有重影。
2. **能单独动**：把 `arm-long.png` 绕肩转 15 度，把 `cloth.png` 往下挪 100 像素，接缝处都不露硬边。
3. **布掉了也对**：去掉 `cloth.png`，短手完整，没有布留下的残影。
4. **一样长**：两张 equal 层的拳头到肩的长度差不超过 5%。
5. **没有字**：所有成品层上都没有文字、数字、符号、水印。
6. **预备姿势的比例**：和对应的平静图比，头高差不超过 3%，脚底线差不超过 10 像素。
