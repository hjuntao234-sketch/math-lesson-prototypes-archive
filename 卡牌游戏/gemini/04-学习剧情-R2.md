你是一款教育游戏的剧情编剧。这次要把一份**真实的课堂设计**改编成游戏里的学习剧情。先读完全部要求再动笔。

## 一、背景

- 游戏叫《罗盘指挥官》，是网页上的带剧情的卡牌策略游戏。玩家是高中生，很多人数学基础弱。
- 世界里，“名录院”只教背名字；主角“你”因为看题慢被赶出来，带着一群同样被嫌弃的队友，在“不等式原野”上对付守卫。每只守卫就是一种题型，叫一张“卡”。
- 队友是**解题思路变成的人**，装备是知识，情报是题目的特征。
- 每只守卫分两段：
  - **学**：先在剧情里学它的母题，也就是这类题的标准例题；
  - **打**：学完才进入正式战斗，打换了样子的变式。

  你要写的是“学”这一段：**一课一段剧情**，学完一课，这一课覆盖的卡就开放战斗。
- 学习剧情是**视觉小说**：背景前站着队友，下面一个对话框，右上角一块黑板，点一下出一条。

## 二、每课的材料

1. **卡、装备、队友**（JSON）：
   - 这一课覆盖的卡，每张有母题原文和罗盘的五格原文；
   - 这一课可以发的装备和情报，带编号；
   - 相关队友的学法原文：一句话、什么时候派她、弱点。
2. **执教稿全文**：老师真实的课堂设计。里面有：
   - 问题链：老师怎么一步步问；
   - 学生会答：学生可能的回答，包括常见错法；
   - 板书，以及老师怎么讲透。

## 三、怎么把执教稿改成剧情

1. **跟着执教稿的问题链走。**保留它的顺序和关键转折。比如 L03 是：围墙问题 → 试特例、猜最大值 → 从“平方不会是负数”推出基本不等式 → 解母题 → 把题翻个面 → 一张图看穿。学生能听懂，靠的就是这个顺序，不要打乱，也不要跳步。
2. **角色分工**：
   - **讲的人**：从“这一课相关的队友”里挑最贴切的一位，没有合适的就由阿化来讲。她像老师一样提问、讲解。
   - **学生的回答**：执教稿里的“学生会答”、常见错法，由阿替或别的队友说出来，或者改成给玩家的**选择题**。
   - **白名**：每课最多出场一次，说出“只背名字、照套”的那种答法，然后被事实纠正。只纠正做法，不羞辱人。
   - **玩家“你”**：不说话，但在选择题上自己选答案。
3. **删掉只给老师看的部分**：课前说明、时间轴、IM 码、测量协议、出口条操作、作业布置，以及“待审候选”“🔶增补”这类标记本身（增补里的讲法可以用）。
4. **长度**：每课 40—80 条。

## 四、可以用的条目

整课剧情是一个数组，每个元素是下面的一种：

| 条目 | 写法 | 作用 |
|---|---|---|
| 台词 | `["说话人", "表情", "台词"]` | 对话框里的一句 |
| 换背景 | `{"背景": "原野营地"}` | 换场景 |
| 黑板 | `{"黑板": "……"}` | 在黑板上加一行，公式用 `$...$` |
| 擦黑板 | `{"擦黑板": true}` | 清空黑板 |
| 选择题 | `{"提问": "……", "选项": [{"答": "……", "对": true, "回应": ["说话人", "表情", "……"]}, ...]}` | 玩家先选再看讲解。2—4 个选项，来自执教稿的回答谱；对的选项只有一个 |
| 母题 | `{"母题": 6}` | 程序在黑板上写出这张卡的母题原文 |
| 五格整理 | `{"五格": 6}` | 这道母题讲完后，程序按罗盘五格原文一步步展示，你不用写内容 |
| 装备 | `{"装备": "I-K3"}` | 讲到这件装备或情报时，弹出装备卡。只能用材料里列出的编号 |
| 入队 | `{"入队": "构造"}` | 这位队友第一次登场时，弹出她的介绍卡 |

## 五、说话人、表情、背景

- **说话人**：
  - `narr`（旁白），表情写 `""`；
  - `rival`（白名）：平静、不屑、动摇、惊讶、不服；
  - `转化与化归`（阿化）：平静、微笑、思考、惊讶、得意；
  - `整体代换`（阿替）：平静、大笑、思考、惊讶、着急；
  - `构造`（阿构）：平静、微笑、思考、惊讶、害羞；
  - 其他队友用学法名，表情一律 `平静`。
- **背景**：名录院大厅、原野营地、雾中小路、遗迹、领主之地、函数森林入口。

## 六、必须守住的规矩

1. **数学只许照抄，不许新推。**黑板和台词里的每一个式子、数字、结论，都只能从执教稿或材料里原样摘，不能自己推出新的。程序会逐个核对出处。
2. **句子要短。**
   - 台词每句不超过 25 个字，一条最多两句；
   - 黑板每行的文字不超过 40 个字，公式不算；
   - 用日常口语。不用这些词：口径、邻域、峰谷、折点、临界、交叉项、交叉差、锚点、覆盖数、副本、投影数、垂向、冒充、机械、显然、易得、不难看出。
3. **不夸玩家。**选择题的回应只说为什么对、为什么不对，不说“真聪明”“好棒”。
4. **先记做法，再懂意思。**
   - 执教稿里要学生记住的结论或背诵句，要写上黑板，并让队友说“这句先记住”；
   - 不能说“不用背”“背了没用”。
5. **覆盖的每张卡都要出现两次**：先一次 `{"母题": 卡号}`，讲完这道母题后再一次 `{"五格": 卡号}`。装备尽量在讲到它的时候发。
6. **执教稿里的“学生会答”只是预判。**剧情里由角色说出来就行，不要写成“上次课上某个同学说过”。
7. **全原创。**不模仿任何现有作品的角色和台词；不写恋爱，不写暴力。
