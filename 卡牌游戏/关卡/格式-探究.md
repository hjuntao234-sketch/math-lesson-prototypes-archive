## 0. 通用规矩

- 公式写在 `$...$` 里，`$` 必须配对。
- 说话写成 `[["学法名", "话"], ...]`；单句的写成 `["学法名", "话"]`。人只能用学法名（见 `格式.md` 第 9 节），对手写 `"诺曼"`。
- **说话的人必须已经入队**：探路关看 `卡` 是第几集；领主、遗迹看 `集`（这一屏最早在第几集之后开放）。
- 每句话不超过 40 字（公式按 3 个字算）；人设照 `设定集/人物.md`，每人只说自己学法会说的话。
- 有选项的地方：`选` 2—4 个，**正好一个** `"对": true`；错的选项写为什么错（探路关写 `驳`，遗迹写 `坑`）。
- 式子字段（`式`、`列`、`像`）只能用 `x`、数字、`+ - * / ( ) ^`。

## 1. 探路关：试 → 猜 → 查 → 证

学生自己代数、看图、猜规律，再被队友挑刺，最后用装备证出来，得一张“你发现的”新牌。

| 字段 | 说明 |
|---|---|
| `id`、`卡`、`名`、`地点`、`题`、`开场` | `题` 不写答案，只问 |
| `试` | `人`（谁陪着算）、`式`（要找规律的式子）、`表头`（比 `列` 多两格：第一格是 x，最后一格“加起来”）、`列`（中间几列各自的式子）、`候选`（学生能挑的 x）、`至少`（算对几行后进“猜”）、`错`（常见错答：`像` 是那个错答的式子，`说` 是提示）、`图`（`人`、`x`、`y` 范围、`名`） |
| `猜` | 列表，一条一个猜想。`问`、可选 `前言`、`人`+`引`（开问前谁说什么）、`选`。猜对的选项写 `签`（写进猜想签的话），可写 `要试过`（必须先算过这几个 x，没算过就退回去，`没试` 写谁说什么）、`标点`（图上标出的最低点，检查脚本会核对它在式子上、并且是候选里最小的）。可选 `接着`：`说`、`按钮`、`换式`（`式`、`名`、`点`、`最低`、`图名`：换一个数再试一组，检查脚本核对 `最低`）、`说后` |
| `查` | 列表。`类: "选"`：`人`、`说`、可选 `算`、`问`、`选`（对的写 `签`，补好的猜想）。`类: "填"`：`人`、`说`、`问`、`答`（数字）、`错`、`成`、`成说` |
| `证` | `人`、`引`、`选`（选装备）、`孔`（`[["正", "为什么能盖"], ...]`）、`算` |
| `奖` | `人`（写签的人）、`式`、`正文`、`孔`、`名`（两个起名建议）、`发现` |

## 2. 领主：直接出刀 → 裂开 → 打影子 → 拼回去

| 字段 | 说明 |
|---|---|
| `id`、`路`、`集`、`名`、`地点`、`题`、`开场` | `名` 照守卫起名规矩，说长什么样 |
| `答` | `式`：答案格式，`{0}` `{1}` 是输入框，如 `"最小值 $=$ {0} $+$ {1} $\\sqrt2$"`；`值`：每格的正确数；`注`：怎么填 |
| `常错` | 列表：`值`（错答）、`记`（老师端记一行）、`说`（这时谁说什么） |
| `影` | 2—5 只，一只管一样本事（子问题）。`id`、`名`（甲乙丙）、`本事`、`色`、`人`（打下时谁说话）、`题`（**正好 2 道**：第二道是换了数字的同一种，第一道答错才出）、`带`（两道都错时雅娜带着走的一步步解法）、`牌`（掉下的发现牌，一句话说这样本事怎么用） |
| `拼` | `格`（每一格叫什么）、`接法`（第一步的候选：正好一张 `对`，错的写 `错`）、`顺序`（正确顺序，第一格是接法 id，后面是影的 id）、`错`（`接法放后面` 和每一格 `"0"`、`"1"`…：`{影id: 话, "_": 其余情况}`）、`行`（拼好后每一格写出的那一行算式）、`带着拼`、`终错` |
| `回马枪` | 隔天的换数字同类题，写清最值 |

- 第一次遇到领主（`SAVE.bossSeen` 为假）时可以先打护卫；以后必须先直接出刀。
- 老师端判读由引擎按“影子打下几次、拼接错在哪一步”自动写，不用写进数据。

## 3. 遗迹：石碑 → 方向厅 → 房间 → 出口 → 消化

开放题，不限时，可以分几次来；进度存在本机，再来从上次的房间接着走。

| 字段 | 说明 |
|---|---|
| `id`、`集`、`名`、`地点`、`要证`、`开场` | |
| `石碑` | `出处`、`文`、`问`、`认字`（课外记号先定义）、`说明`、`进门说` |
| `方向` | `引`、`路`（3—4 条：`id`、`名`、`人`、`想`、`走`（试走一下看到什么）、`果`：`dead` 此路不通 / `q` 留个问号 / `ev` 只是证据 / `go` 有戏、`说`）、`深挖`（果为 `go` 的那条）、`深挖说`、`至少试`（深挖前至少试走几条）、`不够说` |
| `房间` | 列表，按顺序走。`id`（不能用 stone、dirs、exit、digest）、`名`、`小`、可选 `说`（进门谁说）、可选 `前链`（已经写好的几行）、`步`（每步 `问`、`选`、`行`：选对后写进链子的几行）、可选 `乱序`、`成`、`章`、可选 `注`、`成说`、`下一` |
| `出口` | `人`、`说`、`牌`（`名`、`式`、`正文`、`孔`）、`招`（`["招名", "一句话"]`）、`问号`（`{"文": …}`，或 `{"路": "B", "有": 试过时写的, "无": 没试时写的}`） |
| `消化` | `问`（真正的信号是什么）、`选`（对的写 `好`，错的写 `坑`）、`招式`（照“看到……就先……因为……但如果……”写）、`回访`（天数列表，如 `[1, 3, 7]`） |

- 方向厅里至少一条死路：遗迹要让学生亲眼看到走不通的路，死路和问号都算成果（出口的徽章会数）。
- 房间里选错时当场说清这条路为什么走不通；属于“试走一下发现走不通”的错选项加 `"死路": true`，计入死路徽章。
