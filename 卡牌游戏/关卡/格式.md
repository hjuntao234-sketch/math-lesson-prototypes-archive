## 1. 一场战斗在做什么

- 一道题是一颗洋葱，一层是一个回合。
- 每一层写清这一层要做的**步**；这一层的心力必须等于步数。
- 打一张牌、答一道问题都算一步，花 1 心力。
- **坑**：打了不该打的牌、点错部位、选错选项、算错，都花 1 心力，并当场说清为什么。
- 心力用完、这一层还没做完，这一层就合上，下一回合从这一层重来；前面剥开的层保留。
- 星级：回合数等于层数是 ★★★，多 1—2 回合是 ★★，再多是 ★。

## 2. 文件

- 一场战斗一个文件：`关卡/第一章/战斗/<卡号>-<次>.json`，例如 `6-1.json`、`6-2.json`。
- “次”表示第几次打这张卡：1 用原题（卡上的 `q`），2、3 用变式（卡上的 `variants`）。
- 序章用 `p1`、`p2`、`p3` 代替卡号。

## 3. 顶层字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 和文件名一样，如 `"6-1"` |
| `卡` | 是 | 卡号（数字），序章写 `"p2"` |
| `次` | 是 | 1、2、3 |
| `名` | 是 | 守卫的名字，四到八个字，说它长什么样（“披外衣的守卫”），不写知识点名 |
| `地点` | 是 | 顶栏小字，如 `"原野 · 求最大、最小"` |
| `背景` | 是 | `path`、`boss`、`garden`、`ruins` 之一 |
| `题` | 是 | 题面，公式写在 `$...$` 里 |
| `答` | 是 | 结果，如 `{"最小值": 7, "取到": "x=4"}` |
| `守卫` | 是 | 见第 4 节 |
| `队友` | 是 | 1—3 个学法名，第一个站最左边（一般是雅娜）。必须已经入队，见第 9 节 |
| `支架` | 是 | 见第 7 节，必须和“次”对得上 |
| `视线` | 次=1、2 时必填 | 见第 6 节 |
| `牌` | 是 | 这一场所有的牌，见第 5 节 |
| `层` | 是 | 3—5 层，见第 5 节 |
| `落笔` | 是 | 见第 8 节 |
| `改条件` | 有最值的题必填 | 见第 8 节 |
| `结算` | 否 | 打完说的一两句话 |

## 4. 守卫

```json
"守卫": {"图": "p2", "部位": {
  "long":  {"点": "arm-long.fist", "名": "伸长的那只手", "标": "一只手：$x$", "标位": [-24, 26]},
  "ground":{"点": "ground", "名": "脚下那条线", "错": "地上只有一条线。先看看它手上。"}
}}
```

- `图`：`素材/守卫/<图>/` 下要有 `guard.json` 和 `pivots.json`。
- `点`：图层名加 `pivots.json` 里的点名，或者 `ground`。
- `标`：贴在部位旁边的式子标签（支架里“标签”为 false 时不显示）。
- `错`：情报牌点到这个部位却不对时说的话。只有拿来当坑的部位才写。
- 守卫的 `pivots.json` 可以写 `"stand": {"y": …}`（11-08 补）：画布上这一行落在舞台地面上，不写就用 `ground.y`。拱桥写 950，开口向上时 U 形底也在画面里。
- `开局`（可选，11-08 补）：开打时先套用的效果列表，写法同第 5.4 节。例如天平开局就左边沉：`"开局": [{"守卫": "swap:scale-level>scale-left-down"}]`。
- 情报步的 `部位` 可以写一组（11-08 补）：`"部位": ["left", "right"]`，点其中哪个都算对。

## 5. 牌和层

### 5.1 牌（`牌`：id → 定义）

| 类 | 必填字段 | 说明 |
|---|---|---|
| `情报` | `名`、`印`、`正文` | 打向守卫身上一处，点亮一条发现 |
| `理由` | `名`、`签`、`正文`、`合` | `合` 写合适的学法名列表。干扰理由的 `合` 为 `[]`，并写 `坑`；`顶` 写各个队友被挂错时顶回来的话 |
| `装备` | `名`、`式`、`孔`、`正文` | `孔` 用“正”“定”“等”之类的字。这一场拿来当坑的装备写 `坑` |
| `问` | `名`、`正文` | 打出时弹出问题，问题写在步里 |

都可以写 `提示`：`[["关键词","白话解释"], ...]`，鼠标停在牌上时显示。

### 5.2 层（`层`：列表）

| 字段 | 说明 |
|---|---|
| `名` | 两个字，如“外衣”“变形”“出刀”“反扑” |
| `做` | 一句话说这一层要做成什么 |
| `心力` | **必须等于 `步` 的个数** |
| `手牌` | 这一层手里的牌 id。**每张都要有用**：要么这一层的某一步要用它，要么是坑（`层.坑[id]` 或 `牌.坑` 写了为什么） |
| `提醒` | 支架“坑提醒”为 true 时显示 |
| `开场` | 这一层开头说的话：`[["学法名","话"], ...]` |
| `步` | 见下 |
| `坑` | `{牌id: "为什么这时候打它是坑"}` |

### 5.3 步（`步` 里的每一项）

| 类 | 字段 | 怎么算完成 |
|---|---|---|
| `情报` | `牌`、`部位`、`亮`、`效果`、`说`、`盖` | 打这张情报牌并点中这个部位。点错部位是坑 |
| `理由` | —— | 把一张 `合` 里有这个队友学法的理由牌挂到她身上。挂了干扰理由或挂错人是坑 |
| `派人` | `分支`：`{学法名: {题板, 效果, 说}}`、`盖` | 点已经挂对理由的队友。没挂理由就点，她会拒绝，不算步、不扣心力 |
| `问` | `牌`、`问`、`选`、`盖`、`效果`、`说`，可选 `换数字` | 选对。`选` 2—4 个，只有一个 `"对": true`，其余都写 `坑`。`换数字` 是同一个问题换了数字的版本，选错过一次以后改问它（防乱点） |
| `出刀` | `牌`、`算`、`填`、`效果`、`说` | 装备的孔都已盖章，并且填对。`填` 每项写 `名`、`答`（数字），`错` 写常见的错答怎么提示（`"_"` 是其余情况） |

- `亮`：完成后写进题板的一行发现。
- `盖`：完成后给哪些孔盖章。
- 一层里“理由”和“派人”成对出现。
- 一个孔必须在用到它的那一步之前已经盖上章。

### 5.4 效果（`效果` 列表里的每一项）

| 写法 | 作用 |
|---|---|
| `{"守卫": "drop:cloth"}` | 这一层图层掉下去，淡出 |
| `{"守卫": "scale:arm-long:0.82"}` | 这一层沿肩收短 |
| `{"守卫": "swap:arm-long>arm-long-equal"}` | 换成另一张图层 |
| `{"守卫": "show:xxx"}` / `{"守卫": "hide:xxx"}` | 显示、隐藏图层 |
| `{"守卫": "dissolve"}` | 守卫散掉（放在最后一步） |
| `{"标": {"部位": "新标签"}}` | 换部位旁的式子标签（守卫就是式子：变形以后标签跟着变） |
| `{"落": "+1"}` | 从长手掉下一块小石头，上面写字 |
| `{"数轴": {"点": [[-1.5, "$-\\dfrac32$"], [6, "$6$"]]}}` | 题板里画一条数轴（11-08 补）。`点` 是 `[值, 标签, 实心?]`，按大小等距排（示意，不按比例）；不写第三项就是空心点 |
| `{"数轴": {"行": [{"名": "M", "段": [[null, -1.5], [2.5, null]]}]}}` | 在数轴上方画一层集合，`null` 是伸到无穷。同名的行会被替换。端点必须是已经上过数轴的点 |
| `{"数轴": {"亮": {"名": "$M\\cap N$", "段": [[null, -1.5]]}}}` | 在数轴上亮出答案的那几段（一次只亮一组，后写的替换前面的）。只放在答对以后的效果里，别提前亮 |
| `{"数轴": null}` | 把数轴收掉 |

## 6. 视线（看她们盯着哪）

```json
"视线": {"整体代换": {"看": "cloth", "前": "……", "后": "……", "分界": "D1"}, "构造": {"看": "long", "文": "……"}}
```

- 每个上场的队友一条。说的是**她的学法会去看哪里、想怎么处理**，不直接给发现。
- `分界`：这一步完成以前说“前”，完成以后说“后”。

## 7. 支架（第几次就写哪一行，检查脚本会对）

| 次 | 标签 | 视线 | 理由解释 | 坑提醒 |
|---|---|---|---|---|
| 1 | true | 1 | true | true |
| 2 | false | 2 | true | true |
| 3 | false | 0 | false | false |

## 8. 落笔、改条件

```json
"落笔": {"行": ["……"], "清单": ["写了……", "……"]}
```

- `行`：照背诵卡“模板 A”的格式写标准解答，一行一句。最值题必须有“当且仅当……时，等号成立”和最值结论。
- `清单`：3—5 条，学生对照自己写的打勾。

```json
"改条件": {"类": "最小值", "式": "x+9/(x-1)", "定义域": {"op": ">", "a": 1}, "原取等": 4, "原最小": 7,
  "改": [{"op": ">", "a": 2}, {"op": "≥", "a": 5}, {"op": ">", "a": 5}], "自出": {"op": [">", "≥"], "a": [2,3,4,5,6]}}
```

- `式`：一元的式子，只用 `x`、数字、`+ - * / ( ) ^`。
- 三改要覆盖三种结果：不变、端点处取到、取不到。
- 两个字母的题（如 $x+2y=2$ 求 $xy$）先代掉一个字母，写成一元的式子；最大值题写 `"类": "最大值"` 和 `"原最大"`。
- 定义域有上界时写 `"b"`，如 $0<x<2$ 写 `{"op": ">", "a": 0, "b": 2}`。
- 实在化不成一元的式子（如柯西那张卡），写 `"改条件": {"跳过": "为什么化不成一元的式子"}`。
- 定义域右端写成 `≤` 时加 `"bop": "≤"`（默认 `<`）。

**11-07 补（屏上要好读，检查脚本会查）**：

| 字段 | 什么时候写 | 例 |
|---|---|---|
| `元` | 式子里的 `x` 其实是别的字母 | 8-2：`"元": "t"` |
| `显示` | 换了字母，或题面里没有“求 $…$” | `"显示": "t-1+\\dfrac1t"` |
| `说明` | 换了字母；或两个字母并成一个 | `"说明": "令 $t=x^2-4x+8$，那么 $t\\ge4$"` |
| `取等显示` | 原取等不是整齐的数（多于两位小数） | `"取等显示": "\\dfrac{\\sqrt3}{3}"` |
| `最值显示` | 最值不是整齐的数 | `"最值显示": "2\\sqrt3"` |

- `改` 和 `自出` 的端点只用最多两位小数的数（屏上直接显示它）。
- 最值本来就在左端点取到的题（如 $x\ge2$ 时求 $x+\dfrac1x$ 的最小值），`改` 只写两次：一次端点能取到（`≥`），一次取不到（`>`）。
- 离散的（次数必须是整数）、只有上界的定义域，写 `跳过`。

## 10. 坑从哪里来

- 每层至少 1 个坑，全场至少 3 个。
- 坑要是学生真会犯的错，按这个顺序找：
  1. 章节数据 `v4/data-inequality.json` 里的 `packets`（kind 为 `wrong` 的错误链）和 `codes`（I01—I08）；
  2. 卡上每一步的 `alts`（弯路）；
  3. 诊断卷里的常错：负系数跳步、推出方向、取等写错、范围漏写、系数丢了。
- 坑的提示语说清为什么错、错在哪一步，不说“再想想”。

## 11. 语言

- 照 `设定集/语言指南.md` 和“讲法低门槛 6 条”：日常整句，不用行话。
- 气泡、提醒每句不超过 40 字，牌的正文不超过 45 字（公式按 3 个字算）。
- 叫法统一：“基本不等式（模板 A）”。
- 人设照 `设定集/人物.md`：塔莉满脑子找整体，法比娅缺什么补什么，雅娜找见过的样子……每个人只说自己学法会说的话。
