## 调子一句话

**结论就是伤害数字，守卫身上的几何跟着真变。**

学生算对的那条式子，要砸到屏幕上；这一步在数学上改变了什么，守卫身上就要看得见。

## 五条原则

1. **画面只演真的。** 线、交点、扇形、三角形、面积值都从 `meet()` 真实算出来，不画示意的假动画。
2. **先有反应，再有文字。** 算对：先顿帧和震屏，再出结论。算错：先把线摆到反例上，再出“真的 / 你写的”对比条。
3. **轻重分级。** 不是每一步都要最大声。小步轻，过层中，打穿最重。留够差距，收尾才爽。
4. **不挡手。** 一步的演出 1 秒左右。结论飞向题板时已经能操作下一步。“演出：简”能关掉切入和震屏。
5. **不用文字夸人。** 没有“真棒”。爽来自刚才那一步的后果。

## 什么时候发生什么

| 时刻 | 看到的 | 时长 |
|---|---|---|
| 开场 | 队友滑入，守卫砸下来，名字盖屏 | 1.5 秒 |
| 发牌 | 手牌从左下一张张飞进来 | 每张隔 70 毫秒 |
| 手在牌上 | 守卫眼睛跟着鼠标；牌上有没盖的孔，它就红眼咧嘴 | 实时 |
| 出牌 | 面板从牌的位置长出来；打字时公式里的方框跟着填上 | 0.2 秒 |
| 派队友 | 斜切入：立绘、招式名 | 0.47 秒 |
| 算对 | 光束飞向守卫 → 顿帧、震屏、推镜、冲击波、火花 → 守卫打叉眼、挤扁回弹 → 结论盖屏 → 飞进题板高亮 | 约 1.2 秒，0.5 秒后可操作 |
| 连对 | 连续亲手一次算对，“连对 ×n”，音高逐级升 | 0.8 秒 |
| 算错 | 守卫吸气红眼 → 线摆到反例 → 对比条 → 反例砸向雅娜，红屏、掉心、面板抖 | 2.1 秒 |
| 剥层 | 最外一圈真的碎成弧片飞走 | 1.4 秒 |
| 拖线 | 设好线以后随时能按住转，三角形实时变，面积计跟着走 | 实时 |
| 打穿 | 三人竖切入 + 收招词 → 大顿帧 → 守卫碎成上百片 → 星星一颗颗盖下来 | 约 3.5 秒 |
| 输了 | 画面褪色，守卫咧嘴，结算页刻一块墓志铭 | 0.9 秒 |
| 面积最大处 | 拖到那儿守卫放屁；求出最值时放个大的 | 1.1 秒 |

## 轻重分级（`jImpact` 的 p）

| 级别 | 用在 | 顿帧 | 震屏 | 推镜 | 火花 | 全屏闪 |
|---|---|---|---|---|---|---|
| 1 轻 | 查线、盖孔 | 40 ms | 4 | 1.2% | 10 | 无 |
| 2 中 | 算对一步、剥层 | 70 ms | 9 | 2.6% | 22 | 一次 |
| 3 重 | 打穿 | 110–140 ms | 16–20 | 5–7% | 46＋150 | 一次 |

光敏安全：全屏闪一步最多一次，不连闪。系统设了“减少动态”时，自动按“演出：简”走。

## 关卡数据只要写三样，其余引擎自动继承

在 `关卡/卡牌/*.json` 的 `成` 里：

- `章`：砸在屏幕上的结论。要短，去掉公式后不超过 16 个字。不写就用 `现`。`check_deck.py` 查长度。
- `演`：这一步让守卫怎么变。

| 演 | 画面 | 用在 |
|---|---|---|
| `线` | 光从定点沿线冲出去，线钉住，从此能拖 | 设出直线 |
| `两根` | 两个交点炸开光圈，标 ①②，之后变大 | 列出方程 |
| `扇` | 够不到的方向烧红退掉，够得到的留一片金色扇形和两条切线；定点在内时全方向扫一圈 | 判别式 |
| `面` | 定长边发光，三角形撑开，面积计升起 | 写出面积 |
| `顶` | 线自己摆到面积最大处，停住闪光，面积计锁定 | 求出最值 |

- 关卡顶层的 `顶话`：线摆到最大处、守卫放屁时队友说的话。
- 关卡顶层的 `收招`：打穿时的那句话。外点“打穿了！”，内点“没有这条线！”。要和这只守卫最后被打穿的那件事对得上。

换到别的题型，`演` 要补，比如弦中点、定值、定点、双曲线的渐近线。规矩不变：**先想这一步在图上改变了什么**。图上没变化的步骤（比如换元）就只盖结论，不硬加特效。

## 现在还缺的（扩产时做）

- **音效**：现在全是程序合成，没有人耳验过。这是调子里最没底的一块，建议用户先听，不满意就换真实音色。
- **配乐**：还没有。层数越少鼓点越急的方案待定。
- **切入的质感**：现在是纯 CSS 色带和线条。用户买的白色几何素材（`~/Desktop/sozaisyu/`）原定动画阶段用，定调后可以试着叠进切入和结算。
- **守卫的个性**：现在两只只有颜色和钉子不同。扩产后每种曲线应该有自己的受击和挑衅方式。
- **性能**：我这边无头测试稳定 60 帧。教室旧电脑没测，不够快就开“演出：简”，或按帧率自动降粒子。
