# 立绘设计：14 个人，一眼认得出

日期：2026-11-05。Claude（游戏的总监和设计）起草。人设以 `人物.md` 为准，这里只管外形。

## 为什么重做

Gemini 第 3 批（`gemini/回收/原件-第3批/`）用户看了说：“人物太模版化了，我一时半会认不出谁是谁。”问题出在设计上，提示词只给了道具和发色。

| 问题 | 这次怎么改 |
|---|---|
| 同一张脸，只换发色 | 每人单独写脸型、眼型、眉毛，再加一个记号（创可贴、雀斑、眉上疤、泪痣、单眼镜……） |
| 一样高，一样瘦 | 定死身高（147—178 厘米）和体型，按同一比例尺出图 |
| 一样的站姿 | 每人一个专属姿势，看姿势就知道性格 |
| 九个人都是深色长裤配棕靴 | 下半身各不相同：裙、短裤、背带裤、长袍、双色裤…… |
| 道具小，只拿在胸前 | 道具做大，伸出身体轮廓，涂黑了也看得出来 |
| 颜色饱和度相近，转灰度就糊成一片 | 每人独占一个主色，明暗从最白（诺曼）到最黑（奥菈）拉开 |

**三条检验**：
- 涂黑只剩剪影，也认得出是谁；
- 转成灰度，站在一起分得开；
- 缩成指甲盖大的头像，也分得开。

## 逐个

每人五项：
- **脸**：脸型、眼睛、眉毛、记号；
- **头发**；
- **衣服**：上身／下身／鞋；
- **道具**；
- **底色**：没有透明背景时用的抠图底色。

### 雅娜（转化与化归，主角之一）
- **脸**：鹅蛋脸，偏窄的杏眼，青灰色瞳仁，眉毛平而细；嘴角总带一点“我有数”的笑。
- **头发**：黑色短卷发，长到下巴，一边别在耳后。
- **衣服**：青灰色短斗篷，正反两面都能穿，里子是沙色，斜搭在一边肩上，长到腰；深色修身上衣，无指手套；修身长裤，系带高筒靴。
- **道具**：一把小臂那么长的黄铜钥匙，用链子挂在腰侧。
- **身份延续**：沿用现有立绘的斗篷、钥匙、手套和黑卷发，但脸和姿势按上面重画。
- **底色**：品红 `#FF00FF`（斗篷偏青，怕被绿底吃掉）。

### 塔莉（整体代换，主角之一）
- **脸**：圆脸，大圆眼，暖棕色瞳仁；嘴大，一笑露牙；一边脸颊贴着创可贴。
- **头发**：栗色高马尾，扎得很高、发量很足，用一张空白纸签扎着。
- **衣服**：米白衬衫，袖子卷到手肘；橄榄色马甲，兜里插满空白小纸签；琥珀色领巾；及膝工装短裤配深色打底裤，系带矮靴。
- **道具**：举得高高的琥珀色布包袱；斜挎包，纸签从包口支出来。
- **身份延续**：沿用现有立绘的布包袱、纸签和马尾。
- **底色**：绿 `#00FF00`。

### 法比娅（构造）

- **头发**：深赤褐色编发盘髻，几缕碎发垂下来。
- **衣服**：砖红色帆布背带裤，里面是奶白衬衫，袖子卷起；胸兜插一把圆规，口袋里塞着工作手套；裤脚卷起，配厚底工靴。
- **道具**：右肩斜扛一块长木板，比她的肩膀宽；腰侧挂一把折尺。
- **底色**：绿。

### 迪薇（分类讨论）

### 奥菈（退化与边界）

### 奎妲（回到定义）
