# 《罗盘指挥官》语言指南（v0）

日期：2026-11-05。Claude 起草。

## 一、用户的原话（正典）

> 主要是语言要自然，不要人机味太重。
>
> 不要从头到尾全是数学，我们要有剧情有艺术，有跌宕起伏，引人入胜，让读者迫不及待要去解题，又得确保他们获得了解题所需的一切前提条件，要让他们获得解题成功后的快乐和喜悦。至于该有的语言风格，你可以参考真实成熟的产品，无论是小说还是游戏，都可以知道该怎么好好讲话，数学讲解也是一样，参考一线的教学语言。

## 二、人机味长什么样（写完逐条对照，有一条就改）

| 人机味 | 例子（我们自己写过的） | 改成 |
|---|---|---|
| 角色直接说出主题、道理 | “看慢点怕什么，看清了才能走得稳。” | 让她做一件事，道理留给读者自己看出来 |
| 自我介绍念简历 | “我叫雅娜，他们嫌我的招数太土。” | 先让人看见她在干什么，名字顺带出来，被逐的原因藏在一句别的话里 |
| 系统提示混进剧情 | “学习完成。序章第 1 关开放了。” | 用画面收尾：雾、罗盘、守卫还在等 |
| 每句话一样长，一样工整 | 连着几句“先……再……” | 长短句交错，允许半句、打断、语气词 |
| 书面连接词 | “因此”“首先”“综上” | 口语：“那”“所以啊”“你看” |
| 空泛的形容 | “最常见的守卫” | 写具体的样子：“两只手，一长一短” |
| 套话式的夸奖 | “判断得很准嘛！” | 说出玩家具体做对了什么：“你没碰那块布，先看了它下面” |
| 口号重复 | 每段结尾都是“这句先记住” | 要记的话一集里最多点两次，换着说：“背下来”“抄在手心” |

## 三、借成熟小说和游戏的写法（只借手法，不搬原文）

1. **先有画面，后有台词。**一场戏开头用一两句旁白交代在哪儿、看见什么、听见什么，要具体：沙漏、银章、锁链声。
2. **人物要有想要的东西。**塔莉想证明自己有用，诺曼想守住名录院的体面，雅娜想找个肯看的人。台词从“想要”里长出来，别从“要讲的道理”里长出来。
3. **潜台词。**真正要紧的话说一半，另一半让动作说：雅娜不说“我也被逐了”，只说“第十二页和第三页，是同一只”，然后把斗篷翻过来。
4. **笑点来自性格。**塔莉见什么都想贴签起名，连指挥官都差点被贴上一张。
5. **钩子。**每场戏结尾留一个让人想往下点的东西：一只守卫、一句没说完的话、罗盘动了一下。
6. **主角不说话，但被看见。**用别人的反应写“你”：塔莉盯着你手里的罗盘，雅娜注意到你一直在看守卫的手。

## 四、借一线课堂的讲法

1. **先让学生猜、下判断**：“你猜，它最小是多少？”猜错没关系，猜了才有对照。
2. **想出声**：讲的人说出自己第一眼看到了什么，比如“我第一眼看的是，这两项乘起来还剩不剩 $x$”，而不是直接给结论。
3. **一句一个动作**，短句。等号、前提要说全，不跳步。
4. **要记的话用学生自己的话说**：“两个正数，乘起来不变，加起来就有最小。”
5. **夸具体动作**：“你先看了分母”，而不是“真棒”。
6. **比喻要说清到哪儿就不像了**，一句就够。

## 五、成功的快乐怎么写

- 胜利来自玩家刚做对的那一步，剧情要立刻呼应它：守卫散掉的方式，和刚才那一步对得上（两只手一起收短，散成雾）。
- 用身体和画面写松一口气：雾退开、营火变暖、罗盘的指针停稳。少用感叹号堆情绪。
- 队友的反应要像人：塔莉蹦起来、法比娅低头笑、雅娜只说半句。
- 夸奖要稀缺。雅娜那句最高评价“嗯。你看见了。”整季只在大纲指定的地方用。

## 六、前提一样不能少

剧情再好看，也不能让玩家缺了解题要用的东西：
- 要用的式子、条件、记住的那一句，在玩家动手之前都要出现过；
- 打之前出现过的提示，只提示“看哪里”，不替玩家做那一步。

## 七、笑点（2026-11-09 用户：比喻形象，留着，但笑点低；学生喜欢恶趣味）

**路子：恶趣味要和数学绑在一起，好笑的同时把要记的东西带走。**

| 梗 | 带走的数学 |
|---|---|
| 绳子拉到面积最大处，守卫放屁；求出最值时又放一个大的 | 最大值在哪儿。“考卷上你也闻？”“屁不画。”把直觉和计算分开 |
| 墙角的骨头，地上只写了“解”。“写了‘解’，能得一分。” | 考场的真实处境，自嘲 |
| 碑林的墓志铭：“此人设了 $k$，忘了 $x=1$。卒。”“此人算出来等于 1，很开心。卒。” | 丢分点。最后一块碑就是这一关的陷阱 |
| 算错、打输：“此人没讨论斜率不存在。卒。” | 把自己的漏洞记住，也不至于太难受 |
| 塔莉的手抠过肚脐泥，之后所有人躲那只手 | 纯人物梗，连续用，有铺垫有回收 |

**规矩：**
- 恶趣味只拿守卫、拿角色的性格开刀。屁、嗝、泥、死因都行。
- 不碰色情，不拿身体开玩笑。“勒”只对守卫，也不往那边写。
- 不损学生。墓志铭是“此人”，是过去的倒霉蛋。不说学生笨，不说后进生。
- 不拿真实的人和真实的学校开刀。
- 一场戏最多一个大梗，别用屁撑全场。放屁只在它和最大值有关的时候出现。
