## 1. 一场战斗在做什么

一只守卫就是一道题。守卫身上披着**外衣**，战场上盖着**雾**，外衣和雾都代表还没看懂的地方。

学生要做的事有六步，和题型卡的五格流程对得上。

| 步 | 谁来做 | 用什么 | 对应五格 |
|---|---|---|---|
| 看 | 指挥官 | 情报牌：探查守卫身上一处，点亮关键发现 | 凭之前的“看穿” |
| 凭 | 指挥官 | 理由牌：装在队友身上，说明为什么派她 | 凭 |
| 想 | 队友 | 队友出手：变形，守卫的身体跟着变 | 想 |
| 估 | 指挥官 | 选“这一刀有几成把握”，同时给装备的“等”孔盖章 | 估 |
| 做 | 指挥官 | 装备牌：条件孔盖齐后出刀；学生亲手填结果 | 做 |
| 对 | 指挥官 | 守卫反扑，学生把答案代回去，挡住反扑 | 对 |

## 2. 三种牌

### 2.1 情报牌（青绿色，印章）

- 用法：先点牌，再点守卫身上的一处（部位）。探对了，点亮一条**关键发现**，外衣掉一块，雾退开一圈，画面亮一下。
- 探错了位置：不花心力，牌回到手里，雅娜说一句“这里没藏东西”之类的话。
- 一共 15 张，对应章节数据里的 15 种结构（`atoms` 里 kind 为“结构”的条目）。

### 2.2 理由牌（琥珀色，纸签）

- 理由牌的样子是塔莉写的纸签，挂在队友的名牌上。
- 来源：每点亮一条关键发现，抽 2—3 张理由牌进手里，其中至少 1 张是干扰的（“上次就是派的她”“名录上这么写”）。
- 用法：先点理由牌，再点一位队友，把签挂到她身上。
- **对不对**：看这条理由合不合她学法的“什么时候用”（`strategies[].when`）。例如：
  - 整体代换：“条件和目标里有相同的一块。先给这一块起个短名字。”
  - 构造：“已知与目标之间还缺一块。看看补什么能接上熟悉的式子。”
- 对了：她的信任 +1，这一场她的招式升级（多管一步），名牌上出现“想出手”。
- 不对：信任不变，签被她摘下来，她用自己的口气顶一句（例：塔莉“就因为这个？……那我可不一定灵哦。”）。
- 没挂理由就点队友：她会说“派我？先说说为什么。”

### 2.3 装备牌（钢蓝色，公式铭牌）

- 每件装备有 0—3 个**条件孔**，就是装备原来写的“问三句”“什么时候不灵”。
  - 基本不等式：正、定、等。
  - 平方不会是负数：没有孔，随时能出。
  - 作差看正负：一个孔，“要比的是两个式子谁大”。
- 盖章的来源：
  - 情报：例如“范围 $x>1$”盖“正”；
  - 变形后显出来的样子：例如 $t\cdot\dfrac9t=9$ 盖“定”；
  - “估”这一步：例如解 $t=\dfrac9t$ 得 $t=3$，在范围里，盖“等”。
- 孔没盖齐就打出：不出刀，铭牌上没盖的孔亮红，说明缺什么。不扣信任，牌回到手里。这是诺曼“照名字出手”的反面教材。

## 3. 信任

- 每位队友 1—5 级，跨关保留，存在存档里。
- **只涨不掉**。错了只是不涨。
- 涨了的好处：
  1. 这一场她的招式多管一步，例如打包时自动写上新字母的范围；
  2. 到 3 级、5 级解锁她的个人剧情（galgame 人物线）。
- 没被派的队友可以有一句“吃醋”台词，用条件台词写，例如 `p2_sent=fabia` 时塔莉说的话。

## 4. 雾与外衣

- 每只守卫有 $n$ 层外衣（$n$ = 这道题的关键发现数，序章 2—3 个）。
- 战场雾的浓度 = 还没点亮的发现数 ÷ $n$。全点亮时雾散，守卫外衣全掉，露出“熟脸”。
- 外衣条显示在守卫脚下，替代血条。

## 5. 守卫就是式子

- 守卫的每个部位对应式子的一块，部位上挂着这块式子的标签。
- 每次队友出手（变形），守卫换一个形态。剧本里给出每个形态各部位的标签。
- 变成见过的样子时，雅娜（转化与化归）喊一句“这只我见过”，对应的装备亮起。
- 取等时，相应部位一起变形（例：两只手一样长）。

## 6. 回合与心力

- 每回合 3 点心力。情报、装备、队友出手各 1 点，理由牌 0 点。一回合最多 3 个动作，不让后进生一次做太多。
- 守卫有意图（显示在头顶），只用来制造“这回合要做完一件事”的节奏，**不扣学生任何东西**。例：“下回合：雾回来一点”只是画面上雾变浓一些，已经点亮的发现不会丢。

## 6.5 看她们盯着哪（视线提示）

**用户确认**：2026-11-06，用户的原话是：“角色可以加一个弱点提示的功能，就是耗费些什么，可以查看角色一直盯着哪些地方看，希望对重点对哪里就行处理，比如说代换盯着分母（希望把它换成t），构造盯着x（希望凑出分母）。”

- 花 1 枚**提示币**（顶栏金币，开局 3 枚，跨关保留），场上每位已入队的队友各连出一条虚线：从她的眼睛连到守卫身上她一直盯着的部位，旁边写一句她想怎么处理。
- 第 2 关的例子：
  - 塔莉：盯着分母 $x-1$，想把这一整块换成 $t$。布还没掉时，写“盯着那块布：布底下像是一整块”。
  - 法比娅：盯着 $x$，想把它凑成 $(x-1)+1$，和分母配上。
  - 雅娜：盯着整只守卫，在找见过的样子。
- 视线说的是**她的学法会去看哪里**，不直接说答案，也不点亮发现。学生还是要自己出情报牌、自己挂理由。
- 用了以后 11 秒淡出；挂理由、派人出手时立刻收起。出手以后这一场不能再用。
- 剧本写法：在剧本里加 `"视线"`：

```json
"视线": {
  "整体代换": {"看": "cloth", "前": "盯着那块布：布底下像是一整块。想把它整个换成 $t$。", "后": "盯着分母 $x-1$：想把这一整块换成 $t$。"},
  "构造": {"看": "long", "文": "盯着 $x$：想把它凑成 $x-1$ 再加 1，和分母配上。"},
  "转化与化归": {"看": "head", "文": "盯着整只守卫：在找见过的样子。"}
}
```

  “前”“后”分别是相关发现点亮之前和之后的说法；没有前后之分就只写“文”。

## 6.6 特效与预备姿势

- **能出的牌**：边框发青光，一圈亮光沿边框转，鼠标停上去更亮。
- **力量增强**（理由挂对）：脚下一圈光往外扩，光点往上飘，冒出“信任 +1”“力量 ↑”；她换成**预备姿势**，脚下光圈保持亮着，直到出手。
- **出手**：她往前冲，守卫身上一道斩痕，守卫晃一下。
- **装备**（出刀前）：装备的公式铭牌飞到出手的队友身上，脚下光圈变成钢蓝色，再砍。
- 预备姿势现在用动作模拟（身体前倾、往前一步）；正式版换成每人一张“准备出手”立绘，任务稿 `handoff/claude_to_codex/PROMPT-20261106-adventure-guard-parts-ready-poses-gpt.md`。

## 8. 领主裂开（难题）

**用户确认**：2026-11-06，用户问“遇到一个难题，是不是要在boss前把子问题给变成小怪，先打完小怪才能攻打boss”，Claude 建议不强制先打小怪、改成“领主裂开”，用户答：“你的想法好，就按你的来”。

**为什么不强制先打小怪**：
1. 和俯冲式分层相反。要的是先试难题，做不出来再拆；强制先打小怪，就看不出学生本来能不能直接做。
2. 拆好的子问题等于替学生做了最难的一步：想到拆成哪几块、怎么接起来。
3. 强的学生被拖慢，弱的学生需要，所以要可选、按人调。

**规则**：
- **领主一开始就能打。** 直接打赢，记“一刀破阵”，经验多给。
- **打不动就裂开。** 学生在领主身上答错一次，或者自己点“拆开看看”，领主的外衣裂开，掉出 2—3 只小守卫，每只是一个子问题。不扣信任，不扣经验。
- **小守卫掉发现，不掉血。** 打下一只小守卫，得到一张发现牌（例：“$t+\dfrac kt$ 的最小值在 $t=\sqrt k$”）。领主不会因此自动变弱。
- **拼接**：回到领主，学生要把发现牌按顺序贴到题板上。顺序对了才能出刀；接不上的地方，雅娜指出“这一步和下一步接不上”。
- **小守卫尽量是学过的卡**，下潜一次就复习一遍前面的卡。
- **小守卫的题换数字**（照俯冲诊断小样的做法）：打的是同一种本事，但不直接用原题拆出来的式子，免得把拆法送给学生。每只小守卫有两题：第一题错了再来一只同样的（换数字），两题都错记“不熟”，雅娜带着走一遍，照样往下。
- **拼接的第一步从“接法”牌里选**：小守卫不给接法，接法本身就是拼接逻辑。接法牌 2—3 张，颜色、标签一样，不提示哪张对；干扰的接法要是学生真会走的错路（如乘 1 法那题里的“直接用模板 A”“先通分”）。拼对以后，每一格下面写出原题这一步的样子。
- **样稿**：四屏样稿的“领主”一屏（https://claude.ai/artifact/Kq39fKMT8ptxxxruVvab3i ），题目和俯冲诊断小样第 33 份相同：$x+2y=1$，求 $\dfrac1x+\dfrac1y$ 的最小值；回马枪是 $x+y=1$，求 $\dfrac1x+\dfrac4y$（最小值 9）。
- **支架慢慢撤**：某类难题第一次出现时，地图上把领主的护卫小守卫露在明处，可以先打（可选）；以后同类领主不再露护卫，只能靠裂开。
- **存档记录**（老师端能看）：
  - `boss.direct`：直接打赢；
  - `dive.sub`：哪几只小守卫没打下来，说明子问题不熟；
  - `dive.join`：小守卫都打下来了，拼接时哪一步接不上，说明拼不起来。
- 和“俯冲诊断小样”（后进班第 33/34 份）同一个思路。

### 9.5.1 探路关：试、猜、查、证

没有守卫要打，题板换成一本摊开的手账。四步，每步由一位队友带：

1. **试**（苔丝，特殊化）：学生选几个数代进去，自己算出结果填表；芙洛（函数思想）把点画到图上。至少试 4 个数才往下走。
2. **猜**：从 2—3 条猜想里选，里面放“和前面的数据对得上、换个条件就错”的干扰项；雅娜让大家换个条件再试一组，用新数据筛掉错的。猜想写成塔莉的纸签。
3. **查**：米拉（正难则反）找反例，逼猜想补上条件；瑟塔（存在性检验）查等号能不能取到，学生自己算一次。
4. **证**：选已认证的装备证明（装备的条件孔照常盖章）。证完，这条结论变成**学生自己发现的装备牌**，学生给它起名，塔莉写签。

- 猜错、选错都不扣东西，只是被数据或反例驳回。
- 结算写：试了几个数、驳回了几条猜想、最后发现了什么。
- 出场的队友要已经入队（先介绍后使用）；没入队的，由雅娜代说。

剧本写法（`剧本/探路-<卡号>.json`）：

```json
{
  "题": "$x>0$ 时，$x+\\dfrac9x$ 最小是多少？在 $x$ 等于几时取到？",
  "试": {"式": "x+9/x", "可选": [0.5, 1, 2, 3, 4, 5, 6, 9], "至少": 4, "必试": 3},
  "猜1": [{"文": "$x=3$ 时最小，最小值是 6", "对": true}, {"文": "$x$ 越大，值越小", "驳": "..."}],
  "换条件": {"式": "x+16/x", "试": [2, 3, 4, 5, 8]},
  "猜2": [{"文": "最小在 $x=\\sqrt k$，最小值 $2\\sqrt k$", "对": true}, {"文": "最小在 $x=k\\div3$", "驳": "k=16 时最小在 4，不在 16÷3"}],
  "反例": {"代": -3, "补": "x>0"},
  "取等": {"问": "k=16 时，x=4，4+16/4=?", "答": 8},
  "证": {"装备": "基本不等式", "也行": {"作差看正负": "可以证 k=9，但 k 一换要重算"}},
  "得": {"牌": "x+k/x ≥ 2√k（k>0，x>0；x=√k 时取等）", "起名": ["对勾", "一样长"]}
}
```

### 9.5.2 改条件：先估，再验

放在菜园。拿一只打过的守卫改一个条件，学生**先估**结果，再算出来对照。要有“结果变了”和“不存在”的改法。例（第 2 关 $x+\dfrac{9}{x-1}$）：
- $x>1$ 改成 $x\ge5$：取等要 $x=4$，不在范围里；在 $x\ge5$ 上 $x-1\ge4$，函数递增，最小值是 $x=5$ 时的 $5+\dfrac94=7.25$。
- 改成 $x>5$：取不到 5，没有最小值。
- 验的时候只问一件事：**原来取等的那个 $x$ 还在不在新范围里**。在，最小值不变；不在而端点取得到，最小值在端点（学生自己算）；端点取不到，就没有最小值。
- 估“变小”时直接拦下：范围只会变窄，最小值不会比原来更小。
- 前三改固定（$x>2$、$x\ge5$、$x>5$），之后学生自己选 $>$ 或 $\ge$ 和一个数出题；学生出的题记成“你出的守卫”，种进菜园，以后复习会遇到。
- 样稿：四屏样稿的“改条件”一屏。

### 9.5.3 遗迹：开放题

- 地图上的遗迹是一块长期迷雾区，不限时，可以分几次去。例：“两个会证，三个呢”（三个正数的平均值不等式）。
- 做法照罗盘“攻坚·数学科研路径”：列方向 → 快速筛选 → 定向试。
- 进展记在观察笔记：没想通的地方留问号，走不通的路盖“此路不通”章，也算成果。
- 笔记上的四种记号：走通 ✓、此路不通（死路）、只是证据（试数支持猜想，但证明不了“所有”）、留个问号（以后回来）。进度存在本机，可以分几次来，再来时显示“第几次来”，从上次的房间接着走。
- 流程照攻坚题的“科研路径”：石碑读题（课外记号先定义，如三次根号）→ 方向厅列 3—4 条路，每条“试走一下”快速筛选 → 深挖一条，一关一个抉择，选错当场看死路 → 查取等 → 出口得装备和徽章（死路数、问号数也是徽章）→ 消化（回放、提炼招式“看到……就先……因为……但如果……”、约定 1/3/7 天回访；换皮识别、迁移挑战留到正式版）。
- 样稿：四屏样稿的“遗迹”一屏，“两个会证，三个呢”，走柯西 1821 年的两招（先从 2 个推到 4 个，再补上平均数凑成 3 个）。换成立方那条（$x^3+y^3+z^3-3xyz$ 的分解）留成问号，给想挑战的学生以后回来。
