## 1. 总监决定

### 1.1 战斗：洋葱回合

- 一道题是一颗洋葱，一层是一个回合。层数一般 3—5，常见的分法：
  - 看清（剥外衣）
  - 变形（派队友）
  - 出刀（装备、取等、亲手算）
  - 反扑（验算）
- **每层的心力 = 这一层最多需要的步数**。打一张牌、回答一个问题都算一步；被队友拒绝（比如没挂理由就派她）不算步数。
- **坑**：每层至少 1 个，全场至少 3 个。坑要是学生真会犯的错，来源依次是：
  1. 章节数据里的错误链（`packets`，kind 为 wrong）；
  2. 诊断卷里的常错（负系数跳步、推出方向、取等写错、范围漏写）；
  3. 卡上 `alts` 写的弯路。
- 踩坑花掉 1 心力，并当场说清为什么这是坑；这张牌盖上“坑”字章，之后一直显示。
- 心力用完、这一层还没剥开，这一层就合上，下一回合从这一层重来。前面剥开的层保留，不扣信任，不扣经验。
- **星级**：回合数等于层数是 ★★★，多 1—2 回合是 ★★，再多是 ★。
- 老师端记录：每层第一次就剥开没有、踩了哪些坑。

### 1.2 防乱点

- 所有选择都记下“第一次就选对没有”，老师端看这个。
- 选错一次后，同一步换数字再问一遍：数据里给 `twin`；没给就重新打乱选项，并先显示为什么错。
- 每场至少 2 步是填空（结果、取等的值），不全是选择题。

### 1.3 落笔

- 每场打完都有一页“落笔”：照背诵卡“模板 A”的格式给出标准写法，学生在纸上抄一遍，对着 3—4 条检查清单打勾（写了范围、写了“当且仅当……时等号成立”、写了最值结论……）。
- 打完勾盖“已落笔”章，奖励提示币。
- 全游戏统一叫法：“基本不等式（模板 A）”。

### 1.4 支架慢慢撤

每张卡最多打 3 次（原题加变式）：

| 第几次 | 守卫身上的式子标签 | 视线提示 | 理由牌的解释 | 坑的提醒语 |
|---|---|---|---|---|
| 1（原题） | 有 | 1 枚提示币 | 有 | 有 |
| 2（变式一） | 没有，自己读题板 | 2 枚 | 有 | 有 |
| 3（变式二） | 没有 | 不能用 | 只写短签 | 只在踩坑后才说 |

### 1.5 隔天复习

每打完一张卡：
- 在菜园种一只“改条件”守卫；
- 记下 1、3、7 天后的“回马枪”：拿变式题，不给支架。

到期了，营地和地图上会有提醒。

### 1.6 术语和人物都先介绍后使用

- 章节里有一张术语表，第一次出现某个术语时弹出“术语卡”，用一句白话解释。例：定值是“不跟着字母变的数”。
- 检查脚本会查：用到的术语都在表里，并且第一次出现前已经介绍过。

### 1.7 每张牌都要有用

每层手里的牌，要么是这一层必须打的，要么是坑（坑要写清为什么）。不留打不打都行的闲牌。

### 1.8 数值表

| 项目 | 数值 |
|---|---|
| 战斗首胜经验 | 40；★★ 加 10，★★★ 加 20 |
| 落笔 | 经验 10，提示币 1 |
| 探路关 | 经验 50 |
| 领主 | 直接打穿 100；裂开后拼对 80 |
| 改条件 | 每改一次经验 10，估对再加 5 |
| 遗迹 | 走到出口经验 60；死路、问号每个加 5 |
| 提示币 | 开局 3 枚，上限 9；★★★ 战斗加 1，落笔加 1 |
| 视线提示 | 第 1 次 1 枚，第 2 次 2 枚，第 3 次不能用 |
| 信任 | 每场最多加 1（挂对理由那一下）；1—5 级；3 级解锁人物短剧情 A，5 级解锁 B（剧情由批 2 写） |
| 境界 | 沿用现有的经验分级 |

### 1.10 屏幕之间的流程

标题 → 序章剧情 → 序章三关 → 原野地图。

地图上每个据点：
1. 学习剧情（现有的 17 集，讲这张卡）；
2. 战斗（第 1 次）→ 落笔 → 种进菜园；
3. 变式战斗之后才开放。

一条路走完 → 这条路的领主；遗迹是支线，可以不打；四条路都走完 → 章末领主“三影守卫”。

菜园、观察笔记、牌组随时能从顶栏进。

### 1.11 守卫原型（美术）

| 原型 | 题型 | 身体就是式子 |
|---|---|---|
| 双手守卫 | 基本不等式一族（b 路、卡 6—13） | 两只手是两项，取等时一样长（已有分层图） |
| 天平守卫 | 比大小、范围（a 路，卡 1—5） | 两个托盘是两个式子；作差时托盘合成一个，看正负 |
| 拱桥守卫 | 一元二次不等式（c 路，卡 14—18） | 身体是一条抛物线，脚下是 x 轴；根是落脚点 |
| 攻城守卫 | 恒成立、参数（d 路，卡 19—25） | 从多个方向同时进攻，最低点那一处最难守 |
| 折线守卫 | 绝对值（卡 26—29） | 身体由几段折线连成，关节是分界点 |
| 镜子守卫 | 证明、强基（卡 30—35） | 有正反两面，要翻面看 |

- 每个原型画一套分层底子，规格照 `立绘-GPT/守卫-p2/`：1200×1100 画布、轴心记录，外加描边阴影。
- 每只守卫只换道具（布、锁链、盾、绳子、砝码……），控制美术量。

## 4. 不变的规矩

- 先介绍后使用（人物、机制、术语）。
- “做”那一步由学生亲手算；理由和条件也由学生自己选、自己认。
- 语言照 `设定集/语言指南.md` 和“讲法低门槛 6 条”。
- 数学每一步都要核；取等的值必须在范围里。
- AI 生成的素材公开时要标注。
