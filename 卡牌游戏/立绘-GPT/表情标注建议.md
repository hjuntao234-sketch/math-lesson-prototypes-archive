## 方程思想
- L02 / 剧本[21]：**皱眉**。原句：先松开吧。两个人绑着，谁也走不了自己的极端。 理由：看见绑腿互相牵制，关切地劝先松开。
- L16 / 剧本[16]：**微笑**。原句：那两包你们没拆。天平旁边，还放得下。 理由：发现天平旁仍给自己留位置，温柔回应同伴。

## 特殊化
- L01 / 剧本[50]：**兴奋**。原句：代 $a=2, b=-1$！左边 $4+1=5$，右边 $8+2-5=5$，碰上了！ 理由：亲手试中取等的一组，重复感叹碰上了，是苔丝的发现时刻。
- L07 / 剧本[104]：**惊讶**。原句：这只……怎么有点眼熟？ 理由：突然认出有点眼熟的守卫，省略号表现迟疑的惊觉。

## 数形结合
- L07 / 剧本[7]：**专注**。原句：你看这里。土比这条线低，水才漫过去。 理由：你看这里配合沿土坡画线，是伊露投入观察的招牌时刻。
- L07 / 剧本[102]：**微笑**。原句：画板搁这儿。你要看哪段，我给你翻。 理由：主动留画板、愿意为同伴翻图，语气温柔。

## 存在性检验
- L06 / 剧本[30]：**怀疑**。原句：六，在哪儿取？ 理由：追问六到底在哪儿取，是瑟塔最鲜明的核验时刻。
- L16 / 剧本[78]：**微笑**。原句：我问六在哪儿取，碗就放下了。后来那组数，真的找着了。 理由：真的找着了直接表达核验完成后的欣慰。

## 函数思想
- L16 / 剧本[17]：**出神**。原句：桥边我画的图，也带到这里了。取不到的那个点还在。 理由：回望桥边旧图和一直保留的空点，视线远移呈现短暂追忆；不是数学讲解。
- 只有这一条有足够明确的回忆情境。其余多为平静讲解，不为凑两例而硬加表情。

## 放缩
- L05 / 剧本[58]：**认真**。原句：分母加起来呢？题里给的，是这个和吗？ 理由：玛尔嘉收起随和，追问是否真是题给定的和。
- L05 / 剧本[93]：**微笑**。原句：刚才那行，你把分母加过了。我看见了。 理由：营火边留饭位并肯定塔莉确实查过条件，是温和的认可。

## 分类讨论
- L08 / 剧本[11]：**微笑**。原句：等天亮再选。先别把雨披塞到锅底。 理由：顺口打趣雨披垫锅，宜轻笑而非夸张大笑。
- L16 / 剧本[80]：**微笑**。原句：那场雨过后，两套包都还在。没用上的那包，也没扔。 理由：未用上的那包也被留下，感受到自己的准备被接纳。

## 退化与边界
- L08 / 剧本[7]：**警觉**。原句：奥菈。要是根本走不成呢？ 理由：别人备晴雨时，她率先警惕根本走不成的边界。
- L09 / 剧本[85]：**警觉**。原句：先等等。它也可能不是二次方程。 理由：先等等直接叫停，警惕二次项消失。

## 回到定义
- L10 / 剧本[9]：**较真**。原句：负三里远，要倒着提水回来吗？ 理由：把负距离追问成倒着提水，较真又有一点可爱。
- L10 / 剧本[23]：**较真**。原句：先看符号写的是什么。距离不会小于零。 理由：要求回到符号的含义，坚持距离非负，是她的招牌提醒。

## 正难则反
- L12 / 剧本[31]：**坏笑**。原句：正面挤不进去，我绕过来了。米拉，镜子借你看。 理由：用绕过正面打趣自己的登场，最符合米拉反着说话的神态。
- L16 / 剧本[83]：**微笑**。原句：领主那天，正面挤不进去。我绕了一次，你们就给我留了位置。 理由：这句重在同伴留位置的感谢，用真诚微笑而不是继续坏笑。

## 构造
- L13 / 剧本[59]：**惊讶**。原句：它们有底稿。有人在这里出过题，再把题留在门上。 理由：灰下露出试题字样后发现守卫有出题底稿，是剧情意外而非日常讲解。
- L16 / 剧本[14]：**害羞**。原句：绳边那回，桩子还没钉。你们真等我把缺的那块补完了。 理由：法比娅回忆同伴真等她补完，含蓄道出被信任的触动；是较需总监复核的一条。

## 需要Claude复核
- 法比娅 L16[14] 害羞、芙洛 L16[17] 出神属于基于回忆语境的轻度演出判断；台词没有直接写脸红或失焦。如希望更克制，可保留平静。
- 没有为用全素材而强塞表情：迪薇无明确放声大笑台词，因此大笑暂不标；其他惊讶也只在有意外时使用。
- 连续同情绪的普通讲解维持原标记。选择题各选项是独立分支，必要处单独建议，以免某个分支未获得提醒神态。
