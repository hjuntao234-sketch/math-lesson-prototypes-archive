# 7-3 第一遍：塔莉整体代换

仅看 `页面/7-3-r1.html#7-3` 可见文字与截图，逐步 UI 操作。没有读 JSON、源码、答案数据或他人走查，没有 autoplay。这是智能体弱基础高一学生模拟，不是真人教学验证。

实际完成四层并到落笔页：5 回合、2 星、1 坑。截图 `7-3-r1-result.png` 两颗金星、一颗灰星。首次过层为“解绳✓、收拢✓、出刀✗、拆包✓”，经验+50。没有真实纸笔抄写，没有勾选盖章，也不声称独立掌握。

## 实际路径

- 第1回合：“从乘积解开”→图中雾镜（可见坐标946,464）；“把范围带上”→脚下。给出 2y=1/x 与两正项积为3。
- 第2回合：“整块换个名字”挂塔莉，再点塔莉出手。可见说明“挂一张理由，再点对应队友行动”，这次操作没有猜第二步。
- 第3回合：Q1 已给出 3x=1/x，于是 x²=1/3。模拟常见错法，选 x=1/3,y=3/2（把平方值当原数）。反馈明确判错。再答时排除已错选项和负数选项，选择正根那一项；心力耗尽，本层自动重来。此处反馈后选对不能算自主会求根。
- 第4回合：再选正根那一对；出刀填 A=2、B=1/3，页面接受分数写法。
- 第5回合：核验题给定 x=√3/3,y=√3/2，选 xy=1/2、3x=2y=√3、最小值2√3。结算后点击“落笔：在纸上写一遍”。
- 心力空后先 read，都是自动转层或重来，未点“结束回合”。

## 原话与卡点

| 原话 | 弱基础疑问/判断 | 建议 |
|---|---|---|
| “由 xy=1/2 得 2y=1/x” | 怎么把积变成倒数？x、y 还在时，弱基础学生容易把“移过去”当口诀。 | 写出先乘2成2xy=1，再除以正数x。 |
| “整块换个名字 / 换成 u” | 到底哪一整块？点之前不知道将换x、3x、还是整个目标。 | 给出可见动作目标：把√3x看成一整块。 |
| “令 u=√3x>0，则 x=u/√3。3x+1/x=√3(u+1/u)≥2√3；等号需要u=1。” | 为什么突然选√3？为什么又成u+1/u？为什么u=1？ | 先提√3，看到√3x与1/(√3x)互为倒数，再命名；说明u=1/u且u>0。 |
| Q1直接“3x=1/x，于是 x²=1/3” | 塔莉刚说等号u=1，下一张为什么又换回x的相等关系？ | 说明u=1还原为√3x=1，与3x=1/x是同一取等点。 |
| 错答：“你把 x² 的值当成 x。这对数虽满足乘积，3x与2y却是1和3。” | 定位错误、代回反证有效；但不会开方的学生知道错了仍不知怎样改。 | 补x>0，x=√(1/3)=√3/3；再由y=(1/2)/x算√3/2。 |
| “亲手结算…最小值写作 A√3，取等时x²=B。” | A/B再引入字母，但输入标签“根号前的系数”“x²的值”清晰，足以照题填。 | 保留清楚标签；不要把该填空当完整独立证明。 |
| “包里的u是1，原来的x可不是1。” | 口头提醒有用，但最好与还原式并列，不只是提醒别错。 | 写u=√3x=1→x=1/√3。 |

## 有效部分与保留边界

“查看雾镜”“点脚下”配合实际镜子和地面，定位比6-3的抽象“两端”更明确。正数范围和乘积条件留在题板上便于回看。最后核验明确分清 A=2 与完整最小值2√3，有实际纠错价值。

“心力用完了。点右下的结束回合”依旧与自动转回合行为冲突，按边界只记录。落笔提供完整基本不等式范文，没有整体代换的完整落笔范文；本遍不能据此验证学生掌握了塔莉的整体代换。
